# GP208 Alanté Sport (Golden)

A **front-wheel-drive** power chair sold as the "Alanté Sport", like the
older [[GP205-Alante-Sport]]. It's a different chair: lighter, faster,
40 A, and its freewheel levers work the other way. Seat code listed on
[[Golden-Seating-Systems]]. Link to [[Golden]].

## Documents on file

- [[Alante Sport Owners Manual (GP208)]] (Jun 2018)

## Specs

| | GP208 | GP205 (2021 OM, for comparison) |
|---|---|---|
| Speed / range | 4.3 mph / 15 mi | 3.5 mph / 16.5 mi |
| Controller | PG VR2, **40 A** | PG VR2, 50 A |
| Size | 41.5 × 25 in | 39.5 × 22.25 in |
| Turning radius | 28 in | 25 in |
| Assembled | **146.5 lb** (base 66, seat 37) | 157 / 154 lb |
| Batteries | 2-U1, 21 lb each | 2-U1, 22 lb each |

300 lb capacity, Medicare K0823, 230 × 75 front tires, 6 in casters,
2.5 in front anti-tips, captain's seat 18 × 18 in.

## Service notes

- **Diagnostics:** VR2 10-LED flash codes on [[TruCharge-Diagnostics]].
- **Freewheel: levers back = freewheel, forward = drive**: the
  **reverse** of the GP205–207 ([[Freewheel-Mode]]).
