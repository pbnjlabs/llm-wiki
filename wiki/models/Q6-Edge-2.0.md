# Q6 Edge 2.0

Quantum mid-wheel-drive chair, the generation before the Edge 3. Spec
sheet only on file.

From [[Q6 Edge 2.0 Specifications]] (Rev H, Sep 2019):

| | |
|---|---|
| Class | B (Group 3) |
| Capacity | 300 lb |
| Max speed | 6.25 mph; **3.5 mph with iLevel** (UK 4 mph, 3 mph iLevel) |
| Range | up to 19.7 mi; 17.71 mi with knobby tires and 62 Ah batteries |
| Ground clearance | 2.7 in at battery tray |
| Turning radius | 20.5 in |
| Length / width | 35.5 in without front riggings / 24.4 in (28.9 in with armrests) |
| Drive wheels | 14 in pneumatic or solid |
| Casters | 6 in or 8 in solid, front and rear |
| Suspension | ATX (Active-Trac with extra stability) |
| Weights | base 138.6 lb; batteries 38 lb each; total under 388.6 lb |
| Batteries | two 12 V **NF-22** |
| Charger | 8 A off-board |
| Max slope / climb | 7.5° (US) / 3.5 in |

Electronics (2025 chart): **75 A QLNES or 120 A Q-Logic 3**, 2-pole
motors. The original Edge before it shipped with Q-Logic NE/NE+ or
legacy Q-Logic ([[Q6-Edge]]), which [[Q6 Edge Basic Troubleshooting]]
and the original Edge's dealer guides cover. The 2017
[[Q6 Edge Parts Replacement Guide (INFMANU4845)]] is titled "Q6 Edge"
and fits the original; check the IPB before using its parts or torque
values on a 2.0.

## Kits on file

- **Caster arm swap 6 in ↔ 8 in** ([[Q6 Edge 2.0 Caster Arm Kits (INFINFB3544, INFINFB3559)]]):
  front caster arm 20 N·m, rear 55 N·m, struts 8–12 N·m; then **set the
  front spring length: 73.8 ± 1.5 mm with 8 in arms, 80 ± 1.5 mm with
  6 in arms** (Pride calls this step critical).
- **iLevel retrofit** (with the Edge 3): Q-Logic 3 + AAM, suspension
  enhancers, switch paddle adjustment, reprogramming
  ([[iLevel Retrofit Instructions (Edge 2.0-3, Edge HD-Z, Stretto)]], [[iLevel]]).
- Fender lights retrofit kits exist in the PQ-365 library (not pulled).
