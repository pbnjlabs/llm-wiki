# Super Portable (SC15)

Pride's lightest scooter on file, **41.6 lb without battery**, folding,
with a carbon-fiber seat. Spec sheet only
([[Super Portable SC15 Specifications (INFINFB4573)]], Rev A, Jul 2024).

| | |
|---|---|
| Capacity | 300 lb |
| Max speed | 4.5 mph |
| Ground clearance | 1.85 in at motor, 3.7 in at mid-deck |
| Turning radius | 51.62 in |
| Reversing width | 18.43 in as printed (**probably a misprint**: narrower than the scooter) |
| Length / width | 37.2 / 21.54 in; wheelbase 29.45 in |
| Height | 37.28 in; **11.81 in folded** |
| Tires (solid) | 7 in front, 8 in rear |
| Range (11.7 Ah) | 10.1 mi at 220 lb, 8.8 mi at 300 lb |
| Seat | non-removable folding, carbon fiber and recycled cotton, 15.71 × 14.76 in; seat height 11.73 in, seat-to-deck 16.61 in |
| Drive | 200 W brushless transaxle |
| Brakes | regenerative + electromechanical |
| Battery | **lithium-ion 11.7 Ah (8 lb) or 16 Ah (9.8 lb)** |
| Charger | off-board |
| Max slope / climb | 6° / 1.57 in |

No minimum-voltage figure for the SC15 battery is on file; Pride's
general rule still applies: **don't load-test lithium**
([[Lithium Battery Field Inspection Instructions]]).
