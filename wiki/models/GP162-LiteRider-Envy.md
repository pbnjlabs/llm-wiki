# GP162 (LiteRider Envy)

Rear-wheel-drive power wheelchair. Sold with **two different controller
families** under the same model number, confirmed directly from the IPB's
electrical parts list — not a running production change, both appear as
current catalog options:

- **PTC / PG VR2 controller** variant — see
  [[LiteRider PTC Service Guide (GP162, PG VR2 Controller)]]. Uses the
  [[TruCharge-Diagnostics]] 10-bar scheme (wheelchair-adapted, split into
  left/right motor codes).
- **LiNX controller** variant — see
  [[LiteRider Envy LiNX Owners Manual (GP162)]] and
  [[LiteRider Envy LiNX Supplemental Insert (GP162)]]. Uses the distinct
  7-code [[LiNX-Diagnostics]] scheme, plus OONAPU power-up interlock and a
  drive-inhibit chasing-light sequence not present on the PTC variant.

Two chassis sub-variants also exist per the IPB: **GP162B** (basic frame,
seat post shared with the older "LiteRider PTC GP160") and **GP162C**
(distinct frame, seat swivel with built-in lock).

## Specs (LiNX variant, from Owner's Manual)

- 300 lb weight capacity, 3.5 mph max speed, 15.5 mile range
- 40A controller, 2×22AH batteries
- Freewheel mode (rear-axle lever), thermal rollback (auto speed
  reduction on controller overheat — not a fault), main circuit breaker
  with manual reset button

## Key procedures

- **Assembly**: remove 2 battery deactivate blocks before first power-on
  (ships deactivated to protect batteries in transit) — same pattern as
  GL111/141's shipping-block batteries.
- **Disassembly for transport**: splits into 4 pieces (front half 37 lb,
  rear half 36 lb, seat w/arms 23 lb, battery pack 27 lb).
- **Seat/comfort adjustments**: seat height (2 fixed positions via center
  post), arm width, armrest angle, footrest angle/height, joystick
  bracket length — joystick can be relocated to either armrest.
- **Battery charging**: 8-hour full charge; new batteries need a 12-hour
  initial conditioning charge even if the gauge shows full. Charges via
  the joystick port or directly at the battery pack.
- **Diagnostics**: see [[TruCharge-Diagnostics]] (PTC/VR2 variant) or
  [[LiNX-Diagnostics]] (LiNX variant) depending on which controller the
  unit has — check before troubleshooting.
- **Seat belt install**: swap one arm-width-adjustment screw per side for
  a seat-belt anchor knob.
