# SRE-3050 (Bruno Elan)

Bruno's "Elan" straight-rail residential stairlift — the current
generation, successor to the [[SRE-3000]] (same "Elan" branding, same core
architecture, updated 2026 hardware/procedures). Variants: SRE-3050,
SRE-3050CAN, SRE-3050G.

## Specs

- 300 lb (136 kg) capacity
- 24VDC, 16A direct-drive self-locking motor, 442 lb-in (50Nm) torque,
  25.5 rpm output, right-angle worm gearbox
- 8dp integrated gear rack on rail, spur gear on gearbox output shaft
- Max speed 18 ft/min; max incline 45° (52° special order)
- Seat swivel: 0° (riding), 67°, 90° (67°/90° only at top landing)
- Braking: dynamic motor braking (via motor controller) + worm gearbox +
  electro-mechanical motor brake + overspeed protection — see
  [[Overspeed-Safety-Brake]]
- Charger: 105-230VAC/1.5A in, 24VDC/1A out, continuous monitoring, full
  primary cutoff
- Rail lengths: 15'6" (4.7m) and 19'8" (6.0m) standard, cut to fit

## Not recommended for

- Scoot-pivot wheelchair transfers (full body weight on a single armrest,
  no leg weight-bearing)
- Users with leg weakness / uncontrolled knee-buckling during stand-to-sit
  transfer

Bruno directs these users to the [[SRE-2010]] Elite instead.

## Key procedures

- **Rail cutting**: never cut a section shorter than 24" (610mm); when
  splitting length across two rails, cut ≥12" off one rail first, don't
  cut the ends used for the joint.
- **Carriage LH/RH conversion**: move circuit-board jumper LH↔RH, re-route
  sensor connector, remount front cover — required before sliding carriage
  onto rail for a right-hand install (factory ships LH-ready).
- **Rail Cross Pin Installation** (2026 install manual only, not present in
  the 2015 SRE-3000 manual): a drilled safety pin near the bottom of the
  gear rack, using Bruno's SRE Cross Pin Drill Template and a 1/8"
  (3.2mm) bit — appears to be a newer safety addition not carried over
  into the SRE-3000 doc.
- **Overspeed**: see [[Overspeed-Safety-Brake]].
- **Folding rail** (manual or power): see [[Folding-Rail]]. The Elan
  carriage takes its own Folding Rail Carriage Safety Bracket
  (SRE-30609WG), distinct from the Elite's, mounted on the downward safety
  panel.
- **Rail mounting/anchoring**: see [[Rail-Mounting-Guidance]] — the same
  cross-model anchoring reference used for SRE-2010.
- **Diagnostic modes**: multi-user (default) vs. single-user, jumper on
  circuit board (left+middle pins = multi-user, middle+right = single);
  full audio/visual diagnostic code table shared with SRE-2010/SRE-3000
  boards.

## Known issue: brake troubleshooting (shared with SRE-3000)

Symptoms: grinding noise from carriage, 4-short-beep code, carriage starts
then stops, brake hot to touch. Bruno's tech support guide documents this
as a shared SRE-3000/SRE-3050 procedure (same carriage circuit-board
family):
1. Test the board: probe brake tabs with a multimeter while commanding
   movement — should read ≥22VDC in either direction; less than that (with
   24VDC present at the board) means the board needs replacing.
2. Test the on/off circuit breaker switch: temporarily reroute the grey
   brake lead to bypass it; if noise disappears the switch is faulty.
3. Test the brake itself: remove 3 Allen bolts (3mm) holding the brake
   unit on top of the motor, run the unit with the brake removed — if the
   grinding stops, the brake unit itself needs replacing; if it continues,
   suspect the motor or gear rack.
