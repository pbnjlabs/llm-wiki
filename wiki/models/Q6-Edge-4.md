# Q6 Edge 4

Quantum's newest Edge (2025). Mid-wheel drive, the fastest of the Edge
family. Spec sheet only on file.

From [[Q6 Edge 4 Specifications (INFINFB4695)]] (Rev B, Jul 2025):

| | |
|---|---|
| Class | B (Group 3) |
| Capacity | 300 lb |
| Max speed | **7 mph**; 4.5 mph with iLevel; 4 mph UK |
| Range | up to 18.1 mi on Group 24 |
| Ground clearance | 2.87 in |
| Turning radius | 22.8 in |
| Length / width | 38.27 in without front riggings / 24.02 in (14 in drive wheels) |
| Drive wheels | 14 in pneumatic or flat-free; 14 in knobby flat-free |
| Casters | 7 in flat-free, front and rear |
| Suspension | SRS |
| Weights | base without batteries 154 lb; Group 24 batteries 47.8 lb each |
| Brakes | **4 Nm brakes**, "Intelligent Braking" regenerative + disc park brake |
| Batteries | **Group 24**, 62 Ah (C/5) / 75 Ah (C/20) |
| Charger | 8 A off-board |
| Max slope / climb | 7.5° / 3.5 in (varies by configuration) |
| Switches | all under 5 N |

The 2025 end-to-end chart lists **7 in solid** casters (the sheet says
flat-free), 4-pole motors, and **90 A QLNES or 120 A Q-Logic 3**
electronics; HCPCS codes were "coming soon". Codes:
[[Q-Logic-Fault-Codes]].
