# i-Go (S20)

Pride's **folding lithium** scooter, model **S20**. Spec sheet and owner's manual
([[i-Go Specifications (INFINFB4404)]], Rev B, Jan 2023).

| | |
|---|---|
| Capacity | **275 lb** |
| Max speed | 4 mph |
| Ground clearance | 3.5 in at axle |
| Turning radius / reversing width | 45.9 / 49 in |
| Length / width / height | 44 / 20.35 / 36.5 in |
| Tires | 8 in front, 9 in rear |
| Range | 7 mi at 275 lb, 9.3 mi at 220 lb |
| Weight without battery | 60.6 lb; heaviest piece 30.8 lb |
| Seat | molded polypropylene with cushion, 16 × 16 in; seat height 11.81 in, seat-to-deck 14.61 in |
| Drive | **front-wheel drive, brushless hub motor**, 24 V |
| Brakes | regenerative + electromechanical |
| Battery | **25.2 V 9.6 Ah lithium-ion**, 4.8 lb (lithium type required) |
| Charger | 3.5 A off-board |
| Max slope / climb | 6° / 1.57 in |

**Battery check:** two battery versions exist, **Samsung MEC2000135**
and **Panasonic MEC2200931**; both are bad below **22 VDC** after a full
charge. **Don't load-test lithium**
([[Lithium Battery Field Inspection Instructions]]).

## Owner's manual

[[i-Go Owners Manual (INFMANU5131)]] (2023): removable lithium pack;
main breaker pops out when tripped (rest a minute, push it in toward the
rear; frequent trips = charge more often); 3-pin XLR lithium charger
into the scooter first, then the wall (two red LEDs charging, green
full). Lithium rules: [[Lithium-Ion Battery Product Insert (INFINFB4079)]].
