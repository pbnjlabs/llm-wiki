# SRE-3000 (Bruno Elan — legacy)

Predecessor to the [[SRE-3050]]. Same "Elan" branding and core architecture
(rack-and-pinion drive, folding rail option, overspeed governor,
electromechanical brake); the only documentation on file for it is a 2015
install manual, versus the SRE-3050's 2023-2026 documents — treat this as
the prior hardware generation still in the field, not a currently-sold
model.

## Specs

- 300 lb (136 kg) capacity, 18 ft/min max speed
- 24VDC 2-pole motor, 50Nm torque, 16A max, rack-and-pinion drive
- 1Nm electromechanical motor brake + overspeed governor
- Max incline 45° (52° special order); seat swivel 0°/67°/90°
- Rail lengths (2015 "new" length scheme): 8'/10' sections; 16' (std or
  folding), 18' (folding-only), 20' (std-only) full lengths — up to 32'
  (31'-6" actual) optional track length

## Documents on file

- [[SRE-3000 Installation Manual]] — the only manual for this model in
  this wiki (2015-05-13)

## Key procedures

Structurally near-identical to the [[SRE-3050]] install manual — same
section order, same figures reused (rail prep, joint, folding rail,
carriage LH/RH conversion, seat, finishing). Notable specifics:
- **Standfoot orientation** is safety-critical and shared with SRE-2010:
  standfeet must have the long nose facing the center of the staircase
  with no gap between rail and standfoot at the front — wrong orientation
  can drop the carriage.
- **Circuit board diagnostics**: same multi-user/single-user audio
  diagnostic system later reused in SRE-2010 and SRE-3050 documentation.
- **Overspeed**: reset and regulatory test procedures are the same
  content later reused verbatim in [[SRE-2010]] and [[SRE-3050]] docs —
  see [[Overspeed-Safety-Brake]].
- **Folding rail**: same install/troubleshooting content family as later
  models — see [[Folding-Rail]].
- Does **not** include the "Rail Cross Pin Installation" step present in
  the 2026 SRE-3050 manual — likely a safety addition introduced after
  this 2015 document.

## Known issue: brake troubleshooting (shared with SRE-3050)

Bruno's brake troubleshooting guide explicitly covers "the SRE-3000 and
3050" together as one procedure (shared carriage circuit-board family) —
see [[SRE-3050]] for the full symptom/diagnosis steps.
