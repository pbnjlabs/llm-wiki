# Air Hawk / Eagle HD

**The same physical wheelchair, dual-branded.** Manufactured by
**Nanjing Jin Bai He Medical Apparatus Co., Ltd.** (Qinhuai Rd. 61,
Jiangning Economic and Technological Development Zone, Nanjing, Jiangsu,
China) — sold as **"Air Hawk"** by Gilani Engineering PTY LTD (14
Smithfield Rd, Smithfield NSW 2164, Australia; (02) 8740 8963) and as
**"Eagle HD"** by Discover Your Mobility Inc. (66 E Ten Mile Rd, Hazel
Park, MI 48030, USA; (866) 868-9694). Both manuals share an identical
Technical Parameters table, identical page-by-page procedures, and
identical warranty terms — confirmed by direct comparison, not just
similar specs. Only the model name, cover photo caption, and
distributor-contact page differ. Part of the [[Red Hawk]] folder cluster
— see that page for the full multi-brand picture.

## Specs
- Class A electric wheelchair, single-person, indoor/outdoor
- Max weight capacity: **160 kg**
- Motor: brushless DC, 250W×2, DC 24V input
- Battery: lithium, 6Ah×2, DC 24V, 6-8hr charge time, 18km range with
  two batteries
- Brake: intelligent electromagnetic brake, manual lock/unlock lever at
  each rear wheel (LOCK = motor won't rotate even powered off; UNLOCK =
  free-wheel for manual pushing)
- Front wheels: 7"×1.77" PU solid, 2pcs; rear wheels: 12.5"×2.25" PU
  solid, 2pcs
- Max speed 6 km/h (3.75 mph); max grade 6°; highest obstacle 40mm
- Weight: 23.5 kg without battery, 26.5 kg with two batteries
- Folded size 580×325×780mm; unfolded 960×580×930mm

## Controller
5-button pendant: Power On, Power Off, Speed Increase (+), Speed
Decrease (−), Horn, plus a 360° proportional joystick and a 5-LED
speed/diagnostic display. Flashing LED pattern (rather than a beep code)
indicates faults: lowest LED = low power; 2nd = no joystick signal; 3rd =
charging/under control; 4th = motor connection failed; 5th = brake
disconnected.

## Diagnostic chart (shared exactly across both manuals)
| Flicker pattern | Diagnosis | Fix |
|---|---|---|
| 1× slow | Left motor hall fault | Check left motor welding/hall connection |
| 2× slow | Right motor hall fault | Check right motor welding/hall connection |
| 3× slow | Charger malfunction | Try a different charger; check battery cable |
| 4× slow | Left motor cable fault | Check controller-to-left-motor cable |
| 5× slow | Right motor cable fault | Check controller-to-right-motor cable |
| 6× slow | Left brake cable fault | Check controller-to-left-brake cable |
| 7× slow | Right brake cable fault | Check controller-to-right-brake cable |
| 8× slow | Controller fault | Contact technical support |
| 9× slow | Cable fault | Check controller coupler connection |
| 4× quick | Left motor over-current | Release the joystick to clear |
| 5× quick | Right motor over-current | Release the joystick to clear |
