# Pinnacle SL600

Harmar's higher-capacity straight-rail stairlift — 350 lb max payload
(vs. SL300's 300 lb) and, unlike [[Pinnacle-SL300]], **rated for both
residential and commercial use**: ETL listed to ASME A17.5-2019/CSA
B44.1:19 and ASME A18.1-2020, plus FDA registration (Class II device,
510(k) exempt, product code PCD, ETL-Intertek control number 3148125).
Outdoor installation is still excluded from warranty, same as SL300.

## Differences from SL300 (per the manuals on file)
- Uses a **3-color LED indicator on the armrest** (green/amber/red)
  rather than SL300's separate chassis-mounted status light; a red state
  triggers a red→amber→green self-test sequence on power-cycle
- Folding Rail is presented as a standard feature (no "optional"
  qualifier in this manual, unlike SL300's explicit SL300FR option) — not
  confirmed against an install manual, since none is on file for SL600
- **Power Swivel and Power Footrest do exist for SL600** (SKUs SL600-PS/
  SL600-PF/SL600-PSPF) — confirmed by
  [[Pinnacle Power Swivel and Power Footrest Install Supplement]], simply
  undocumented in the one owner's manual on file. SL600's power footrest
  ships pre-wired to both armrests (SL300 requires manual rewiring to
  switch hands)
- Beep-code table is 1-9 in the owner's manual (includes "FINAL LIMIT
  switch detected", absent from SL300's 1-8 table) and matches
  [[Helix]]'s table exactly — **but the install manual's own beep table
  only goes to 8**, an unresolved cross-document discrepancy (see
  [[Pinnacle SL600 Install Manual]])

SL300 and SL600 share the same chassis-and-wheels subassembly and control
software (`800-00004 SOFTWARE, SL300/SL600`) per
[[Harmar Parts Diagrams]]. A control-PCB schematic independently
confirms **four SL600 chassis sub-variants — STD, RAVE, LLSL, and
HD** — the "SL600HD" named in the rail-length bulletin is a real variant,
not a typo, though none of these four are otherwise documented
individually.

## Warranty
**Limited lifetime** warranty on motor/gearbox/worm gear/gear rack, 3yr
other parts/electrical, 1yr batteries — stronger coverage than SL300's
2yr+10yr-rack scheme. See [[Harmar-Warranty]].
