# TiLite Pilot

TiLite's **pediatric** manual wheelchair. **Weight limit 120 lb (54 kg)**; with
the transit option the rider must weigh **20 lb less**. Axle sleeve **26 Nm**.
Schrader or Presta valves; solid tires need special equipment.

**Transit:** only the factory Transit Tie-Down Option (WC19 and ISO 7176-19) is
for occupied transit; the Wheelchair Transport Option is for an empty chair.
Check the stickers. See [[Transport-and-Tie-Downs]].

Customer support (800) 545-2266.
