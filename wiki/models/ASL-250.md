# ASL-250 (Bruno Out-Sider / Out-Sider with Swing-Away — legacy)

Predecessor to [[ASL-275]]. Same "Out-Sider"/"Out-Sider with Swing-Away"
branding and core architecture (hitch-mounted, folds a platform behind
the vehicle for an **unoccupied** scooter/power chair, optional
Swing-Away arm to clear the tailgate/hatch); the only documentation on
file for it is a 2019 install manual, versus ASL-275's 2026 manual —
treat this as the prior hardware generation still in the field, parallel
to how [[SRE-3000]] relates to [[SRE-3050]].

## Specs
- Max lifting capacity: 350 lb (159 kg) — same as ASL-275
- Installed weight: 85-110 lb without Swing-Away (**lighter** than
  ASL-275's 110-125 lb)
- Hitch compatibility: Class II (1.25") or Class III (2") — same as
  ASL-275
- Height adjustment: narrower standard ranges than ASL-275's single
  "6"-24" via 3 adapters" figure — 12"-19" (Out-Sider alone) or 9"-17"
  (with Swing-Away) using the standard hitch-adapter table, extendable to
  7"-25"/7"-23" with optional adapters (ASL-16442/16446/16488/16491/
  16517/16519 part families, keyed to a 19-row height-to-adapter lookup
  table with two orientations: without Swing-Away and with Swing-Away)

## Platform families (three, vs. ASL-275's four scooter/powerchair-size
variants)
- **3-piece adjustable** — scooters or power chairs; secured by an
  automatic Hold-Tite foot (scooters) or manual retractable belts
  (scooters and power chairs) hooked to a dog-bone bracket on the seat
  underside; ships with 4 optional ASL-16585 support angles (2 factory-
  installed, 2 dealer-installed for wheelbases 34"-37")
- **Modular** — power chairs only, fixed 28.5"x52.2" deck
- **HTP** (ramped platform, ASL-250HTP) — **not present on ASL-275 at
  all**: adds fold-down ramps on each side plus chock/caster plates
  configurable for front-wheel-drive, rear-wheel-drive, or mid-wheel-
  drive power chairs, driven straight onto the platform rather than
  walked on; its own pivot-arm hold-down setup compresses the powerchair
  seat directly (raise the platform until it ratchets, lower 1", position
  the pivot arm, then raise again until it firmly compresses the seat)

## Installation
- Hitch adapter orientation/height determined from a lookup table (same
  pattern as ASL-275), Magnalube on adapter contact surfaces, angle
  adjustment hardware to hold the mount tube vertical (90° to ground)
  before final tightening
- Stainless-steel hardware throughout — Loctite Silver-Grade Anti-Seize
  required on any refastened threads; **never use a pneumatic wrench**
  (self-welds the fastener under high-speed friction/heat); the Class II
  hitch bolt is Grade 5 (three hash marks), Class III uses zinc-plated
  Grade 8
- Power wiring: same battery-direct pattern as [[Vehicle-Lift-Power-Wiring]]
  (black-to-negative-first) — this manual is the one that specifically
  names the inline fuse as an **ATO 30A fuse**, clarifying the
  previously-ambiguous "30A" fuse type on [[ASL-275]]
- Semi-annual maintenance: re-grease telescoping tubes/pivot points with
  Magnalube, check platform tilt (3-6° toward vehicle under load with
  the platform raised), dielectric grease on electrical connections

## Emergency operation
Manual crank on the motor shaft (or a 3/8" electric drill): **clockwise
raises, counterclockwise lowers** — same direction convention as
[[ASL-275]]'s emergency crank.

## Troubleshooting highlights
- Same KEY/UP/DOWN circuit-board jumper technique as ASL-275 to isolate
  keyswitch vs. rocker-switch vs. circuit-board faults
- Weak vehicle battery is called out as a common cause of slow/
  underpowered operation, verified by starting the engine and re-testing
  — identical diagnostic logic to ASL-275
- Adds explicit license-plate-lamp and brake-lamp wiring fault trees
  (traced through the shared lift/trailer-lighting PCB) not detailed on
  the ASL-275 page
