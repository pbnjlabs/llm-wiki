# Buzzaround XL / Buzzaround Lite (GB106, GB116, GB146, GB147)

Golden's mid-size folding travel scooter family. No IPB or Operator
Manual is on file for any of these model numbers yet — everything known
comes from short service/accessory bulletins.

## Documents on file

- [[2-Piece Brake Replacement (LiteRider, Buzzaround XL, Buzzaround Lite)]]
- [[Frame Lock Adjustment (GB116, GB146)]]
- [[Field Alignment Procedure (GB147)]]

## What's confirmed

- **GB106** is branded "Buzzaround **Lite**" (distinct from "Buzzaround
  XL"), but shares the same electromagnetic brake body as GB116/GB146 —
  only the handle shape differs.
- **GB116 and GB146** fold in half (front/rear sections separate) and
  latch together via a frame-lock mechanism with an adjustable bolt/
  receiver-cup mating — see [[Frame Lock Adjustment (GB116, GB146)]].
- **GB147** uses a **tie-rod front-wheel steering linkage** with a
  toe-alignment spec (16 5/8" front track width) — a different steering
  architecture than what the frame-lock document describes for GB116/146.
  **Open question**: it's not confirmed whether GB147 also folds in half
  or is a fixed-frame redesign — no IPB/OM on file to check. Don't assume
  GB147 shares the frame-lock procedure.
- Brake mechanism is **shared with the GL110/GL140 LiteRider** — same
  brake body, model-specific handle only. See [[Brake-Replacement]] for
  the cross-model comparison.
- **Transaxle replacement** (GB106 pre-July-2012, GB116/GB146
  pre-April-2012 old style): mandatory paired controller swap, see
  [[Golden-Transaxle-Replacement]] — shared cross-model doc, also covers
  [[GL110-140-LiteRider]].
