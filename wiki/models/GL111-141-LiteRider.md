# LiteRider — GL111, GL141 (current generation)

Golden's current mid-size travel scooter generation, successor to
[[GL110-140-LiteRider]]. GL111 = 3-wheel, GL141 = 4-wheel. 300 lb
capacity, 5 mph, rear-wheel drive, 90 Amp Dynamics R-Series controller
(same controller part, 3051600170, as [[GC240-340-440-540-Companion]]'s
GC240/340/440 — confirmed in the IPB, not inferred), 2×22AH batteries,
off-board charger, freewheel mode, electro-mechanical brakes.

## Documents on file

- [[LiteRider Owners Manual (GL111, GL141)]]
- [[LiteRider Illustrated Parts Breakdown (GL111, GL141)]]

No dedicated service guide is on file for GL111/GL141 (only the older
GL110/GL140 has one; the drivetrain is shared so much of it likely still
applies, but that's not confirmed from GL111/141-specific documentation).

## Key procedures

- **Diagnostics**: 1-9 beep code scheme, confirmed identical to
  [[Flash-Beep-Diagnostics]] (shared Dynamics R-Series controller with the
  Companion line). Printed on the back of the battery box for field
  reference.
- **Disassembly**: drivetrain separates via a release lever + yellow
  alignment tabs (audible click on reassembly). New battery packs ship
  with a "deactivate block" underneath that must be removed before first
  power-on — scooter won't power on with it installed.
- **Charging**: 6-8hr daily recommended; charge new batteries 12hr even
  if gauge shows full, to condition them.
- **Warranty**: [[Golden-Scooter-Warranty]] applies (rev. 11.17 text
  explicitly lists "LiteRider Series: GL109, GL111, GL141" — note GL109,
  not GL110, in that list).
