# Q6 Edge 3 (standard)

Quantum (Pride) mid-wheel-drive power chair. **Not the
[[Q6-Edge-3-Stretto]]**, which is narrower and has its own specs. Only a
spec sheet is on file for this one; there's **no Edge 3 owner's manual**
(see the index's Missing manuals).

From [[Q6 Edge 3 Specifications (INFINFB3925)]] (Rev D, Oct 2022):

| | |

| Range | up to 19.7 mi; 17.71 mi with knobby tires and 62 Ah batteries |
| Ground clearance | 2.7 in at battery tray |
| Turning radius | 20.5 in |

## Electronics

The 2025 [[Quantum End-to-End Chart (INFINFB4546, 2025)]] lists the Edge
3 with **75 A or 90 A QLNES** only. The same chart says 7 mph is
possible with optional 4-pole motors and Q-Logic 3, and that 6.25 mph
needs Q-Logic 3, so older or special-order Edge 3s may have Q-Logic 3.
**Check the hand control:** an LED-only joystick with Key I/II is QLNES
([[QLNES Basic Operation Instructions (INFMANU5366)]]); a display screen
is Q-Logic 3. The PMS field-note chair's joystick (CTL143976) holds an
**SD card**, which points to Q-Logic 3. Codes: [[Q-Logic-Fault-Codes]]. Motors: 2-pole standard,
4-pole optional.
