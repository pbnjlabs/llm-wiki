# TRU-Balance 3 Power Positioning System (Pride)

Source: [[Tru-Balance 3 Power Positioning Systems BOI]].

Tilt/recline/elevate power seating system mounted on Quantum power bases,
compatible with both [[J6]] and [[Q6-Edge-3-Stretto]] as an alternative to
their standard fixed/manual-recline seats. Operated via the chair's
controller, a specialty controller, or an optional toggle. Max seating
weight: 450 lbs (204 kg) or the power chair's own capacity, whichever is
less.

## Range of motion

- Up to 50° tilt
- Up to 12 in (30.5 cm) of lift
- 85°–175° recline
- Combined tilt/recline up to 175°

Some Power-Tilt + Quantum power-base combinations cap max tilt below 50° —
always check the specific base/seat combination rather than assuming the
full range applies.

## Inhibit matrix

A factory-programmed drive inhibit prevents driving while the seat is
outside safe positioning limits:

| Condition | Elevated | Tilted >20° | Reclined >20° | Tilt/recline >125° |
|---|---|---|---|---|
| Recline Lockout | | | | X |
| Tilt Lockout | | | | X |
| Elevate Lockout | | X | X | X |
| 1/4 Speed | X | | | |
| Full Drive Lockout | | X | X | X |
| iLevel | X | | | |

These inhibits are not user-adjustable — bypassing, reprogramming, or
removing them is explicitly warned against (risk of injury).

## iLevel

Optional elevating-seat feature (also documented from the
[[Q6-Edge-3-Stretto]] side — see that model page). Requires a flat, level
surface to activate; boots restrict front caster movement and obstacle
climbing to 1–1.5 in while engaged; seat can still tilt/recline up to 20°
while elevated; drive speed is capped to a safe reduced value (falls back
to 25% speed if the iLevel-not-engaged warning displays while elevated —
stop and get service if that happens on level ground). Indoor/flat-hardscape
use only, never on uneven or outdoor terrain.

Q-Logic 3 controller indicators specific to this: No Restrictions, Safe
Elevation, Reduce Speed Restrictions, Full Drive Lockout (see
[[Joystick-Controllers]]).

## Armrests (four styles, each independently adjustable)

- **Flip-up** — height/angle/width adjustable, hex-wrench hardware
- **Two-post** — 9–13 in height range in 1-in increments, spring-loaded
  lever removal
- **Heavy-Duty Drop-in** — designed for easy transfer removal, 8–14 in
  height range depending on point measured
- **Pediatric Single-Post Quick-Height** — 7.75–10.75 in total height
  range, tool-free top adjustment via locking pin, bottom adjustment via
  detent bar screws

## Other adjustments

- **Flip-forward back** (optional) — folds seatback forward for easier
  transport, via detent pin or release-lever mechanism (two hardware
  variants exist)
- **Controller position/extension/height** — moves between armrests,
  slides in/out, raises/lowers, independent of armrest style
- **Seatback height/width** — direct hardware adjustment
- **TRU-Comfort cushion system** — lumbar, lateral, and thoracic supports
  attached via hook-and-loop or hardware; cover is hand/machine washable
  ≤140°F (60°C), no bleach, no dryer, no iron
- **Lateral supports** — height/width adjustable on a channel track,
  provider-install-only
- **Headrest** — height/depth/angle adjustable, max 7 in extension above
  the bracket
- **Optional Toggle Operation** — maps tilt/recline/elevate/leg-rest
  functions across 4 different physical toggle styles (single-lever
  4-direction, small 4-direction, 4-button, rocker) — a reference table
  worth pulling up directly when converting a chair between toggle styles

## Warranty

3-year: structural frame components. 2-year: electronics, TRU-Comfort
seatback cushion, Sport Back seatback cushion. 18-month (24-month Canada):
actuator. Excludes upholstery/seating in general, unauthorized
modifications, and damage from battery leakage, misuse, or improper
storage.
