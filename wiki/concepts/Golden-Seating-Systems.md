# Golden Seating Systems

Golden sells a shared catalog of seat sizes/styles across its scooter and
power-wheelchair lines, tracked by a size-code system (SM4, SM5, SM9, SMP,
SMV, etc.) rather than by model. Three reference docs plus one seat
product's own assembly/adjustment instructions.

## Measuring seats ("Measuring Mobility Seats")

Two seat types: **Stadium** (molded plastic, fixed back angle, must be
fully upright to measure) and **Captain's** (adjustable back angle —
remove headrest, align hinge indicator lines before measuring). Usable
depth = distance A-to-B with a square held against the seatback; usable
width = measured 4-3/4" forward of point A. Tolerance ±1/2".

## Seating matrix / size-code catalog ("Mobility Seating Matrix" +
"Mobility Seats")

Confirms seat codes and which models take them as standard (STD),
optional (Opt), or not applicable:

| Code family | Style | Confirmed models |
|---|---|---|
| SM5/SMA/SMB/SM4/SM7 | Stadium | GB1xx, GC2xx-4xx, GL1xx, GA541 (Avenger=STD on its own code), GR575 (Patriot) |
| SM9/SN9 | High-back | GC240/340/440, GP605/620 |
| SMP | Pro-Flex | GP162, GP205, GP207, GP605, GP620 (wheelchairs only — see [[GP6xx-Compass]], [[GP162-LiteRider-Envy]]) |
| SMV/SNV | Van/pan | GC240/340/440, GP605/620 |
| SMH, SMD, SMF, SME | misc single-model codes | SMH=GA541, SMD=GR575 (Patriot — not yet ingested), SMF=GP208 (not yet ingested), SME=GP162/GL111/GL141 |

GR575 ("Patriot"), GP205, GP207, and GP208 appear in these seat docs but
have no manuals of their own on file — noted for a future ingest if such
manuals turn up.

## Proflex Seat (the physical seating base behind the "SMP" code)

Instructions for a metal-frame mobility seating base (push handles,
swing-away leg rests, tilt/angle adjustment) — not a cushion, a full
positioning seat system:
- Back locks upright via a lift-and-latch mechanism; a pull-strap releases
  it to recline.
- Push handle height adjusts via a bolt through one of several holes in
  the handle tube.
- Back angle adjusts by repositioning a tube forward (decrease) or
  rearward (increase) at its mounting bracket.
- Seat angle ("dump") adjusts by moving a cross-bar up (decrease) or down
  (increase).
- Swing-away leg rests adjust independently for length and angle.
