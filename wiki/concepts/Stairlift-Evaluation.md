# Stairlift Evaluation

How PMS evaluates a home for a stair lift. **House practice**, from the
[[PMS Stair Lift Evaluation Form (Rev Mar 2024)]] and
[[Stairlift Evaluation Measurements and Photos]]. For Harmar's
camera-based measuring, see [[Staircase-Measuring-System]].

## 1. Job and user

- Who requested it: private pay, VA medical center or other.
- User height and weight.
- User seated measurements: **seat to head**, **back to knee**, **hip
  to hip**.

  **Feasibility rule (PMS):** add **back to knee + hip to hip**. That
  total must **fit within the stair width while the user is seated on the
  lift**. The limit is **stair width minus 5 in**; e.g. a
  new-construction standard **34 in** stairway allows up to **29 in**.
  
  1. Check the fit with the **handrail in place** (width to the handrail).
  2. If it doesn't fit, check again with the **handrail removed** (full
     width).
  3. Fits only without the handrail: **the handrail has to be removed**.
  4. Doesn't fit either way: **"no bid."**
  
  (Per the human, 2026-09-30.)
- Stair type: straight, curved/spiral, or straight with a flat or
  sloped landing. Indoor or outdoor.

## 2. Measure the stairs

| Measurement | Straight | Curved |
|---|---|---|
| Stair width | ✓ (each flight if more than one) | **Each flight** (required) |
| Stair height (rise) and run (front to back) | ✓ | ✓ |
| Number of stairs | ✓ (per flight) | Per flight |
| **Track length**: stand at the top and let the tape feed to the floor | ✓ | — |
| Handrail removed? If not, inches from the wall | ✓ | ✓ |
| Ceiling bulkhead height | ✓ | ✓ |
| Top and bottom landing L × W | ✓ | ✓ (W across the top/bottom of the stairs); also mid landing |
| Distance to the nearest obstruction, top and bottom (door opening or frame) | ✓ | ✓ |
| Camera pics taken | — | ✓ |

Also, from the PMS eval photo guide: **every stair's width** if they
differ (number them or draw them), and **doorway width, door trim width
and door width**.

## 3. Rules and options

- **Outlet within 4 ft of the stairs** (top or bottom), or an
  **electrician is required**.
- **Rail position is decided by management** when the eval is reviewed.
- **Folding track:** only if the track at the bottom would obstruct or
  there isn't enough room. **Straight rails only.**
- **Seat:** standard or power swivel; **power swivel doesn't work with
  the larger seat**. Seat size **18–19 in** standard or **24 in** larger.
- **Adjustable seat bracket:** for narrow staircases and taller users.
- **Curved rail options:** top overrun **24 in minimum**, bottom overrun
  **36 in minimum**, 90° or 180° park at top/bottom.

## 4. Photos

Take all five: top landing, entire top landing area, bottom landing
area, bottom landing with the stairs, entire staircase. Also shoot the
areas away from the stairs (hallways, rooms) to show room for the rail
and the park position. Photos that cut off part of a landing or the
staircase aren't acceptable.
