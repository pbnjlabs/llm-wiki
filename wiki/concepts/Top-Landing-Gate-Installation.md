# Top Landing Gate Installation (VPL)

Bruno's top-landing-gate installation procedure for vertical platform
lifts. Confirmed on [[VPL-3100B]] and [[VPL-3200B]] — the entire section
(both figures and instruction text) is reused essentially word-for-word
across both install manuals. Gates are sold separately from the lift and
are never free-standing; Bruno recommends mounting to 4×4 posts/framing
and provides angle brackets and mounting holes but not the mounting
fasteners themselves.

## Gate styles covered

- **EMI** (36" high) — hinge tube + latch tube on sill plate, gate wheel
  mounted to interlock
- **ESI** (36" high) — similar, adds a separate gate actuator assembly
- **42" high** — taller version, same sill-plate/hinge-tube pattern
- **Wide gate (90°/adjacent platform)** — for lifts where the platform
  exits at 90° rather than straight through

## Shared install sequence

1. Route wiring from latch tube to VPL (side or bottom exit; specific
   offset for right-hand vs. left-hand gates when exiting the side).
2. Position sill plate flush with the fascia, fasten to entry.
3. Insert hinge tube over sill plate tabs, fasten, verify plumb front-to-
   back and side-to-side; shim if necessary.
4. Remove access cover from latch tube; confirm factory flat washer sits
   against the yoke bracket.
5. Insert latch tube over sill plate tabs, fasten, verify plumb again —
   **critical for door closing speed and latch alignment**.
6. Mount the gate wheel — **orientation and offset-vs-straight selection
   matters** and is configuration-dependent:

   | Configuration | Gate Wheel |
   |---|---|
   | Straight platform, either-hand unit, either-hand gate | Offset (1) |
   | Adjacent (90°) platform, right-hand unit, left-hand gate | Straight |
   | Adjacent (90°) platform, left-hand unit, right-hand gate | Offset (1) |

7. Assemble gate handle and latch plate to the gate.
8. Route the gate harness from the VPL tower to the gate; connect,
   matching wire colors; mount electrical access panel.
9. Insert cap plugs into hinge/latch tube holes; replace access cover.

## Cam/activator adjustment (part of the same interlock)

The activator is part of the gate interlock — a mechanical interlock
released by platform motion, backed by electrical contacts that prohibit
operation while engaged. Adjustment is nearly identical for straight and
90°/adjacent platforms:
1. Verify 3/8"–3/4" (10–19mm) platform-to-gate running clearance.
2. Start with platform 1.5" (4cm) below the landing.
3. Remove (3) screws from platform, loosely assemble gate activator
   bracket, mount to platform.
4. Slide cam so a 2" (5cm) gap exists between gate post and activator's
   flat edge; slide activator vertically until its angled edge just
   touches the cam; tighten.
5. Run the platform up — gate should unlock at landing level. Re-verify
   clearances.
6. With the gate wheel held unlocked, run the platform down — it must
   **not** continue more than 2" (5cm) past unlock before stopping. This
   is the interlock's core safety check.
