# Ramp Install Time Estimates

Install time per component for EZ-ACCESS jobs, from
[[EZ Access Layout Key and Install Time]] (rev 7/10/19). **The sheet's
origin is unknown and it isn't confirmed as PMS's own standard**, so
check these times against PMS practice before quoting labor. To estimate a
job, add up the components on the layout drawing. Times are per piece.

## Ramps, platforms, stairs ([[PATHWAY-3G]])

| Component | Time |
|---|---|
| Ramp section 2', 3', 4', 5', 6' (× 3 ft) | 20 min each |
| Ramp section 7', 8' | 25 min each |
| Platform 4×5 (MP45), 5×4 (MP54), 5×5 (MP55), 5×6 (MP56T), 6×5 (MP65), 6×6 (MP66) | 35 min each |
| Platform 8×5 turn-back (MP85TB) | 40 min |
| Double platform (2 × MP45T) | 50 min |
| Landing pad (5' ALP) | 15 min |
| Stairs | 60 min |
| Ramp bracing (green dot on layout) | 15 min each |
| Platform bracing (red dot on layout) | 20 min each |
| Closure kit / corner kit (MHRPRC / MHRRRC) | 20 min each |
| MRST (ramp support top + legs) / MRLT | 15 min each |
| MUGPP gate post | 15 min |
| Bridge plate (36/48/60 in) | 10 min each |

## Thresholds and portables

| Component | Time |
|---|---|
| Rubber threshold ½–2½ in (RT 1.5, RT 2.5: [[TRANSITIONS-Threshold-Ramps]] mats) | 20 min each |
| Rubber threshold 3–5 in (RT 3, RT 4: modular mat with risers) | 40 min each |
| Aluminum threshold (TAER12/24/36 Angled Entry Ramp) | 10 min each |
| SUITCASE ramp ([[SUITCASE-Ramps]]) | 15 min each |

## Not timed

**Modifications** require prior authorization before the job.

## Worked example

A 24 in rise at 1:12 needs 24 ft of ramp. That is under the 30 in
max rise per run, so one run with no intermediate landing will do.
Build it as 3 × 8' sections off a 5×5 top platform. No bracing is
needed, because nothing is over 36 in high:

- 3 × 25 min for the ramp sections
- 35 min for the platform

That comes to about **1 h 50 min** of listed component time. Handrail
connectors or closure kits add 20 min each. The sheet doesn't say
whether handrails, tie-downs or travel are included, so treat the
result as a minimum.
