# Golden Transaxle Replacement (LiteRider & Buzzaround)

Explicitly named cross-model procedure: replacing an **old-style
transaxle with the new style** on [[GL110-140-LiteRider]] and the
[[GB1xx-Buzzaround-XL]] family (GB106, GB116, GB146).

- Old-style transaxle cutover dates differ by model: GL110/GL140 and
  GB116/GB146 switched prior to **April 2012**; GB106 switched prior to
  **July 2012**.
- Basic swap: remove drive wheels (retain axle keys) → remove old
  transaxle → **replace the controller with a new preprogrammed one at
  the same time** → install new transaxle → reinstall drive wheels with
  axle keys.
- **Critical**: controller replacement is mandatory, not optional — the
  new transaxle's controller programming is specific to it, and the old
  brake/motor-brake assembly is not interchangeable with the new
  transaxle. Skipping the controller swap causes erratic behavior
  (stopping too quickly or lurching forward).
- This is a summary-level doc; it defers to the model-specific service
  manual for full step detail.
