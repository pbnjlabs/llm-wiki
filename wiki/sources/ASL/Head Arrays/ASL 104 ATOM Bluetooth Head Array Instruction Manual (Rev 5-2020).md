# ASL 104 ATOM Bluetooth Head Array Instruction Manual (Rev 5-2020)

Two-page sheet for the **ASL 104 ATOM Bluetooth Electronic Head Array**
(digital, switch-type). Feeds [[Alternative-Drive-Controls]].

- **Connects to:** LiNX connector or Input Module, MK6i connector / MK6i
  digital interface, Omni or Omni 2, Enhanced Display or SCIM.
- **Pads:** Curved Wing 5 × 3.25 in, Standard Wing 3.25 × 1.5 in, Element
  and Proton Wing 3 × 2 in. Mount: ASL 606.
- **Interface:** power light, **attendant on/off switch**, directional
  LEDs, BT pairing switch, **switch timer dial**, 6 DIP switches, and a
  magnetic protective cover with cable guides. Ports: **user switch mono,
  mode change mono**, powered **reverse/mode (SEL)**, **left**,
  **forward**, **right**.
- **Switch timer:** sets the long-hold time on both the **mode** port
  (long hold or double tap on the reset switch to change modes in R-net
  and Q-Logic) and the **user** port.
- **DIP switches:** **1** ON = SEL port is a mode/reset switch, OFF = a
  reverse switch; **2** ON = Bluetooth discoverable (pairing); **3** ON =
  powers up with the chair, OFF = turn it on with the attendant switch;
  4 and 5 future use; **6** ON = beep on each activation.
- **Bluetooth:** press and hold the user switch or attendant switch.
  **1 beep = head array on, 2 beeps = off, long beep = Bluetooth mode.**
- Reset switches: 204 USB proximity (micro USB, with **826** micro-USB to
  mono cable), 314, 320; mounts 930, 930B, 611.
- Same moisture and reset-switch warnings as the FUSION. Two-year
  warranty.
