# ASL 110 FUSION Head Array Instruction Manual (Rev 3-2022)

Two-page instruction sheet for the **ASL 110 FUSION Proportional and
Digital Head Array** ("Powered by ATOM Technology"). Install and
programming steps per electronics are in
[[ASL 110 FUSION User Installation Guides (LiNX, Q-Logic, R-net, Permobil)]].
Feeds [[Alternative-Drive-Controls]].

- **Connects to:** LiNX Input Module, **MK6i (needs ASL 171)**, Omni or
  Omni 2 (R-net), Enhanced Display or SCIM (Q-Logic). 60 in cable, 9-pin
  connector.
- **Pads:** Element or Proton Wing (3 × 2 in). Mount: **ASL 606** multi-axis
  headrest hardware.
- **Interface ports:** (A) Bluetooth pairing, (B) ASL 165 display and
  programmer (Molex), (C) Bluetooth light, (D) back pad, (E) **mode port**,
  (F) **user port**. Front: light sensor (auto-dims), power light
  (**green = driving, amber = Bluetooth mode**), on/off membrane switch,
  Bluetooth light (**flashing green = not paired, solid = paired, off =
  Bluetooth off**).
- **User-port switch with the ASL 165 display:** a tap selects the
  highlighted item; holding moves down the list. Tones: **1 beep on/off,
  2 Bluetooth, 3 next function, 4 next profile.**
- **ASL 165 FUSION Display, Programmer and Attendant Control:** programs
  the FUSION, shows what the user is controlling, and works as an
  attendant control or full override. Its menus: [[ASL 165 FUSION Display and Programmer Interactive Guide]].
- Reset switches: ASL 204 / 208 proximity sensors, 304B wobble, 314 ultra
  light, 320 pulse; mounts 930 / 930B swing-away, 611 armrest bracket,
  683 magnetic mount.
- **Safety:** a **reset switch must always be plugged into a mode port
  programmed to stop the chair.** Moisture on a sensor can cause
  unwanted movement: not in rain or snow, not with wet hair, no porous
  cover. **Not a head support in a vehicle.**
- Warranty two years; **the vinyl isn't covered**. ASL, Spicewood TX,
  **800-626-8698**, asl-inc.com.
- Accessories: ASL 558 mouse emulator, 557-3 switch receiver, 545E Tecla,
  540 12 V battery for using an ATOM control on a manual chair (lasts up
  to 3 days).
