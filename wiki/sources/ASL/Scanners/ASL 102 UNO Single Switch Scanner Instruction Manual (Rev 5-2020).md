# ASL 102 UNO Single Switch Scanner Instruction Manual (Rev 5-2020)

Two-page sheet for the **ASL 102 UNO Bluetooth Single Switch Scanner**:
drive with one switch while the display scans the directions. Assembly:
**UNO interface**, **UNO display**, **UNO attendant control** (standard)
and the wheelchair connection. Connects to a LiNX Input Module, MK6i
digital interface, Omni or Omni 2, or Enhanced Display / SCIM. Feeds
[[Alternative-Drive-Controls]].

- **How it drives:** the display's blue light scans in frequency-of-use
  order; hold the switch when the light is on a direction and the chair
  moves that way while held; on release the scan **goes straight back to
  forward** (except BT and AUX, which need a sustained hold to return).
  The display dims in the dark.
- **Timing dial:** scan rate, **0.2–4.0 s per light** (arrow left =
  slowest, right = fastest).
- **DIP switches (up = ON):** **1 veer**: OFF = forward, right, left,
  reverse, select (then BT, AUX if on); ON = adds veer left/right (after
  forward if forward was used). **2** = 1 s switch delay before returning
  to forward. **3** = enable Bluetooth (to ASL 545 Tecla E or 557-3; stays
  in BT until the switch is held **5 s**). **4** = enable AUX (the switch
  drives whatever the 9-pin output is plugged into, e.g. an AAC device;
  hold 5 s to return). **5** = beep each scan step. **6** = Bluetooth
  pairing.
- **Interface:** program DIP switches, timer dial, power light, BT light,
  on/off switch; rear: wheelchair connection, mono input for the scanner
  switch, switch input for the Bluetooth output, display/attendant port,
  9-pin output.
- **Attendant control:** mimics the drive control; clips to a push handle
  on a flexible cord. **Select while the user drives stops the chair
  only if the electronics are set up for it** (check with the ATP); from
  stop, select moves to the next function (e.g. seating). The attendant
  can drive while the user is in BT or AUX.
- **ASL 802/4 ECU interface cable:** 4 mono plugs from the auxiliary
  port (tilt, recline, computer, AAC); forward plug = select in AUX.
- Same moisture and reset-switch warnings. Two-year warranty.
