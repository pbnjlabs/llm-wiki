# Permobil Joystick Module IR Quick Start

One-page Permobil sheet (DOC0125-00) for teaching the **PJSM** joystick to work
as an **infrared remote** (TV, cable, etc.).

- **Learn a code:** hold soft key 1 (blue, upper left) to open settings; scroll to
  **IR Setup**; pick the device; choose the command; select **learn code**; point
  the remote at the PJSM IR receiver and press the button **twice**; a green check
  confirms. Repeat per command, then Exit (the chair asks for power off/on twice).
- **Use it:** enter IR Mode (mode toggle, switch or shortcut soft key);
  forward/back picks the device, left/right enters it and sends commands.
- The PC IR Configuration tool can also set it up.
