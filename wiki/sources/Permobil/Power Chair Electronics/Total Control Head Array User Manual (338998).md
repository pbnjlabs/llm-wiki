# Total Control Head Array User Manual (338998)

20-page user manual (Ed 3, 2024-08-29, order no. 338998 eng-US) for
Permobil's **Total Control Head Array**, an alternative drive control for
R-net chairs.

- **Occipital pad:** two proximity sensors (forward/rearward). **Control
  arms** (left/right turn) use proximity sensors or **egg switches**.
- **On/off switch** on the back of the occipital module. **LEDs:**
  steady green = ready, steady amber = a control is active, flashing
  amber = standby.
- Mode changes go through the mode switch (with an Omni menu, or a
  sequence). Reverse by a dedicated reverse switch, or by toggling
  direction. Opposite commands at once: return the head to neutral
  before a new command.
- **Removal:** loosen the screws, disconnect the cables, press the
  buttons to swing the arms out, turn the lever counter-clockwise and
  lift it off the backrest.
- **Covers and sensors must be dry**: moisture can trigger the sensors.
  Clean weekly (daily in sweaty weather); check daily that the sensors
  and switches are fixed in place. Replace torn covers with Permobil
  parts.
- **It is not a headrest.** If the chair is used as a seat in a motor
  vehicle, replace the head array with a headrest approved by the
  wheelchair manufacturer.
