# Permobil Back Support Sizing Guide

23-page Permobil sizing guide for its **back supports**: the **Comfort** line
(Unite 1, 2, 3, Unite 1 Wing, Embrace, Contour) and **ROHO AGILITY** backs.
For each: a width × length matrix of standard (x) and custom sizes (widths
10–28 in, lengths 10–22 in) and a dimension table per SKU (e.g. U1-BS12W12L):
foam height, shell height, wing height and offsets, foam depth, shell width,
foam width, shell depth, internal shell width. Use it to match a replacement
back or check fit.
