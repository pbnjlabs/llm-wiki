# Harmar Product Spec Sheets

Four single/double-page "Product Specifications Sheet" PDFs, grouped into
one source page (each is a compact data table, not narrative
documentation).

- `Harmar-MKT-000126-C-HighlanderII-SpecSheet-V1.pdf` (06/30/23,
  MKT-000126 Rev C) — VPL400-VPL1400 full spec table: tower heights per
  model (VPL400 72" through VPL1400 197"), 2/3hp 90V DC motor, 26:1
  gearbox, 1" ACME screw, 9.5-15 FPM lift speed, 2 or 4× 12AH batteries
  for the optional UPS backup, 3yr parts/1yr battery warranty, rated
  commercial and residential.
- `Harmar-MKT-000203-B-VPL-400-X-SpecSheet-V1.pdf` (06/30/23, MKT-000203
  Rev B) — VPL400-X spec table, otherwise electrically/mechanically
  identical to the base VPL400 (same motor/gearbox/screw/speed) but
  **rated residential only** and carrying a shorter **2-year parts
  warranty** (vs. the general HighlanderII line's 3-year) — see
  [[Harmar-Warranty]].
- `Harmar-MKT-000030-C-AL425-SS.pdf` (11MAR2022, MKT-000030 C) — AL425
  2-axis inside hoist lift: 400 lb capacity, 66 lb install weight, 30" min
  headroom required, 3-year warranty.
- `Harmar-MKT-000031-C-AL435T-SS.pdf` (11MAR2022, MKT-000031 C) — AL435T
  tailgater hoist lift: 400 lb capacity, 81 lb install weight, reaches 43"
  to curbside or over a 24" tailgate, passenger-side install only,
  3-year transferable warranty.
