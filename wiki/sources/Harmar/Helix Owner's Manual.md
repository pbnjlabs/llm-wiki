# Helix Owner's Manual

P/N 610-00039-01 Rev D, 24SEP2021. Owner's manual for Harmar's **Helix**
curved stairlift, covering the CSL500, CSL510, CSL511, CSL560, CSL570,
CSL589, CSL590, CSL595 series models (per the warranty section) — "Helix"
is Harmar's marketing name for the CSL-series curved stairlift.

## Covers
- Safety definitions/cautions, 350 lb max payload
- Key features: retractable seat belt, optional emergency stop, footrest
  obstruction sensors, seat swivel release bars, folding armrests/seat/
  footrest, optional key lock, 3-color status light (red/yellow/green),
  diagnostic port
- Basic ride operation, remote control, mid-level parking/charging
- 6-month and annual maintenance checklists (chassis/rail, charging
  station contacts, gear rack safety stop, mounting bolts)
- Major-fault beep-code table (1-9) — see [[Harmar-Stairlift-Beep-Codes]]
- Limited lifetime warranty (motor/gearbox/rail) — see [[Harmar-Warranty]]
