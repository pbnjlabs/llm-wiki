# Highlander II with Enclosure Installation & Service Manual

P/N 630-00153 Rev B, 15JUL2022. Dealer/technician manual for the same
Highlander II with Enclosure VPL family as the
[[Highlander II with Enclosure Owner's Manual]]. Far more detailed than
the owner's manual — this is the primary technical reference for
[[HighlanderII]].

## Covers
- ASME A18.1 Section 2 (commercial) vs. Section 5 (private residence)
  applicability; 24-cycles/hour (VPL400-800) vs. 12-cycles/hour
  (VPL1000-1400) duty rating
- Full tool list, box contents, concrete pad spec (4" min, 3500 PSI),
  positioning/anchoring, enclosure panel/dome/top-landing-gate assembly
- Electrical connection (junction box hot/neutral/ground + battery-backup
  brown-wire disconnect pair), permanent power (120VAC, 15A dedicated
  circuit)
- Full 4-LED status-code table (much more granular than the owner's
  manual — flood switch, travel-time, motor temp/current, safety-pan,
  float-switch, out-of-service conditions)
- Control board reference: 32-LED diagnostic layout, 3 momentary switches
  (brake/reset/service), 3 permanent cuttable configuration jumpers
  (3-stop/TG/AUX)
- Gearmotor: 2/3 Hp, 26:1 worm drive, 25% duty cycle / 45-min max
  continuous run + 2h15m rest
- Battery backup: 2× (VPL400/600) or 4× (VPL800-1400) 12V SLA batteries,
  60A fuse, 24V/2A 4-stage charger, 1500W inverter
- Emergency lowering/evacuation procedure (same as owner's manual, with
  more mechanical detail)
- 6-month/annual maintenance schedule
