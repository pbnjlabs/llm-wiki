# VPL400-X Install Manual

P/N 630-00159 Rev B, 21JUL2023. Install/service manual for the
**VPL400-X**, a **residential-only** 4' vertical platform lift SKU —
distinct from the generic VPL400 covered by the [[HighlanderII]] family
manuals (which can be residential or commercial). Only ASME A18.1-2020
Section 5 (private residence) applies; there is no Section 2/commercial
path for this SKU.

## Covers
- Same core 4' tower architecture, OSG switch, and ACME-screw drive as
  the base [[HighlanderII]] platform
- Uses "**Bypass Mode**" (not "Service Mode," the term used in the other
  Highlander II manuals) for the same 30-minutes-UP-only pre-wiring
  install function
- A "BRAKE RELEASE" toggle switch, used only during emergency lowering or
  positioning, that lets the platform drift under control
- Otherwise mirrors the platform guard panel, gate, ramp, fascia, and
  limit-switch procedures in the base Highlander II install manuals
