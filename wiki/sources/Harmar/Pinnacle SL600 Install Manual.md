# Pinnacle SL600 Install Manual

P/N 76015 Rev K, 23JUL2024 — note the part-number pairing with the
owner's manual's P/N 76016 (install = 76015, owner's = 76016), a
different numbering pattern from every other Harmar doc in this batch.
First install/service manual on file for [[Pinnacle-SL600]] — closes the
"no install manual" gap noted when SL600 was first ingested.

## Covers
- Nearly identical rail/chassis/footrest/seat install procedure to
  [[Pinnacle SL300 Install Manual (2026, Rev L)]] (same 7'9" rail
  sections, same zero-intrusion option, same 30°-45° stair-angle range)
- LED-based (not beep-count-only) safety-sensor check: "if the LED
  indicator light is not green, check the safety sensors"
- Folding rail install (SL600FR) — Harmar Technical Support must be
  contacted for a left/right handing conversion (unlike SL300, no
  in-manual reversal procedure is given for SL600)
- **Beep-code discrepancy found**: this install manual's major-fault
  table stops at 8 codes (no "FINAL LIMIT switch detected"), but the
  already-ingested [[Pinnacle SL600 Owner's Manual]] lists 9 codes
  including a final-limit code. Not resolved — flagged as a
  cross-document inconsistency rather than assumed to be an error in
  either document. See [[Harmar-Stairlift-Beep-Codes]]
