# Highlander II Install Manual (no enclosure)

P/N 630-00113-01 Rev G, 27SEP24. **A genuinely different product from
the already-ingested
[[Highlander II with Enclosure Installation and Service Manual]]**
(P/N 630-00153): this document's title omits "with Enclosure,"
and its "Key Vertical Platform Lift Elements" diagram shows platform side
panels and an optional platform gate instead of full tower enclosure
walls/dome/doors. Same core electronics, ACME-screw drive, OSG,
battery-backup, and 4-LED status architecture as the Enclosure version —
see [[HighlanderII]] for the combined writeup covering both
configurations.

## Covers
- ASME A18.1-2020 Section 2 (commercial, 3 runway-enclosure sub-options)
  vs. Section 5 (private residence)
- "Service Mode" bypasses safety-switch wiring for 30 minutes during
  install (runs UP only, not DOWN) — activated either by a PC-board
  button or by swiping a magnet between the blue paddle and E-stop switch
- 4' vs. 6'-14' tower platform-connection procedures differ (4' bolts
  directly; taller towers need the platform supported and the carriage
  driven up in Service Mode to align mounting holes)
- Platform guard panel install (straight-through and 90° configurations),
  optional platform gate, auto-folding ramp, top landing gate, lower
  landing call stations
- Battery backup install including an optional cold-weather
  battery-warming-blanket kit with a thermostat controller (set to 70°F)
- Full installation tower check (OSG, final limit, safety-nut switch,
  safety pan, float switch) — matches the Enclosure manual's checklist
