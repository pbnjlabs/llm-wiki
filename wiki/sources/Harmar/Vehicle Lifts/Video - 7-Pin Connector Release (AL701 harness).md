# Video: 7-Pin Connector Release (AL701 harness)

Harmar product-launch video, 2:03, by a Harmar tech-services rep in
LiftSquad's training bay. It introduces Harmar's **7-pin trailer
connector harness** for outside (hitch) lifts, shown on a Ford F-150
with an AL-series lift ([[AL-Series-Outside-Vehicle-Lifts]]). The file
is dated Nov 2025; no date in the video. The video gives no part number;
the [[Outside Vehicle Lifts Install Manual (2025, Rev D)]] calls it the
**AL701** 7-pin connector harness.

| Time | Point |
|---|---|
| 0:15 | Saves **30–60 min of install time** compared with running the standard harness to the battery. |
| 0:24 | The plug is keyed (slotted) like any 7-pin, so it only goes in one way. **Pull the vehicle socket's tab down and push the plug in.** |
| 0:38 | Then connect Harmar's connector to the lift. |
| 0:46 | Most vehicles work straight away. If not, call tech support. |
| 0:57 | **F-150: the truck must be running.** When the dash shows **"trailer connected"**, click **OK** through the prompts. |
| 1:33 | At the lift, the **red light** shows power; the lift then runs. |
| 1:00 | On-screen: tech services **866-378-6648**, TechServices@harmar.com. |

## Checked against the manuals

The install manual adds the limits the video skips: use the AL701 **only
with an OEM 7-pin socket**, **check the vehicle in Harmar's Vehicle
Compatibility Calculator first**, **never on an aftermarket 7-pin**, and
follow the instructions packed with the harness. The AL701 instructions
aren't on file. Bruno's equivalent 7-pin kits and trailer-recognition
problems are in [[Vehicle-Lift-Power-Wiring]].
