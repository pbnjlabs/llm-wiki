# Bulletin: License Plate Riser Installation (AL901, AL904)

P/N 630-00175 Rev A, 21APR2025. Affects **AL901 and AL904** — two Outside
Vehicle Lift model numbers not named in the main AL-series owner's/
install manuals or hitch-weight tables; add to
[[AL-Series-Outside-Vehicle-Lifts]]'s model list as confirmed-but-thinly-
documented variants.

## Covers
Relocating the license plate/light onto a riser bracket, with separate
procedures for "new style" and "older style" motor heads (the older style
requires opening the motor cover and splicing a wiring-harness extension
with heat-shrink; the newer style just re-uses longer mounting screws to
hang the riser). Torque specs: 12 ft-lb for the standard self-tapping
mounting screws, 8 ft-lb for the fallback bolt/nut/washer kit if a
mounting hole strips.
