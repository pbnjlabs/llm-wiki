# Video: How to Set the Limit Switch on AL800 Series Truck Lifts

Harmar training video #1, 1:31, by a Harmar Technical Services tech.
Adjusting the **rotation stop** on an AL800-series truck-bed lift
([[Hoist-Series-Inside-Vehicle-Lifts]]), outdoors on a pickup. No date.

| Time | Step |
|---|---|
| 0:11 | At the base of the post: **two set rings (cams)** and **two limit switches**. Adjust the set rings. |
| 0:21 | Goal for the stowed position: boom **roughly square to the cab, angled slightly toward the bed**. |
| 0:33 | **Loosen the set ring's Allen (set) screw** with an Allen key. |
| 0:45 | With the remote, rotate the boom back in until it's square to the cab. |
| 0:52 | Turn the set ring until it **presses the limit switch**, then **tighten the set screw**. |
| 1:09 | Check: that limit switch is pushed in and the other is free. **Run the boom out a little and back in**; it should stop at the same square position. |

No Allen key size given.

## Checked against the manuals

Matches [[Truck Lifts Installation and Owner's Manual (AL800 Series, 2017)]]
p. 21: "the amount of allowable rotation is determined by the cams;
loosen set screw and rotate as required" (Figure 21-1, rotation cut-off
switches). The manual adds: to **reverse rotation** (passenger-side
install), swap the wires at the rotation motor and you may need to flip
the cut-off switches.
