# Harmar Parts Diagrams (Manufacturing BOMs)

Nine engineering exploded-view/BOM drawings (revision histories, torque
specs, ASME Y14.5 drafting notes) — manufacturing references, not
dealer/tech documentation. Grouped into one source page; individual part
numbers aren't transcribed here (see the raw PDFs for those), only the
facts they reveal that aren't documented anywhere else in the wiki.

## Pinnacle stairlift chassis (confirms shared electronics platform)
- `Harmar-SL300 Chassis.pdf` (DWG 130-00581, Rev K) and
  `Harmar-SL600 Chassis.pdf` (DWG 130-00594, Rev E) — both reference a
  shared assembly `130-00673 ASSY CHAS & WHLS SL300 & SL600` and a common
  `800-00004 SOFTWARE, SL300/SL600` part, confirming SL300 and SL600 run
  the same control software/chassis-and-wheels subassembly despite their
  different capacities. The SL300 chassis drawing also names the parts
  as **"SL300 PINNACLE LITE"** (top/bottom shroud silkscreen) and lists
  companion docs `610-00058- SL300 PINNACLE LITE OWNER'S MANUAL` and
  `630-00100 SL300 PINNACLE LITE INSTALL MANUAL` — "Pinnacle Lite" appears
  to be SL300's internal/engineering name. SL600 chassis drawing also
  shows two alternate chassis builds sharing the same base assembly:
  "LLSL" and "RAVEII" data-label variants, not otherwise documented.
- `Harmar-Chassis with obstruction sensors.pdf` (DWG 130-00582, Rev J) —
  the obstruction-sensor-equipped chassis variant referenced by SL300COS
  in the order forms.

## Pinnacle folding rail assemblies
- `Harmar-Lower Folding Rail assembly.pdf` (DWG 130-00549, Rev H) and
  `Harmar-Upper Folding Rail assembly.pdf` (DWG 130-00550, Rev H) — LH
  folding-rail hardware, available in 3 powder-coat color codes
  (base/RAL9016/RAL9006), consistent with the folding-rail reversal
  procedure in [[Pinnacle SL300 Install Manual (2026, Rev L)]].

## Outside Vehicle Lift assemblies
- `Harmar-al-100-12_L.pdf` / `Harmar-al-100-12_L_dupe1.pdf` (byte-identical,
  md5-confirmed) — AL100 hold-down-arm/platform assembly.
- `Harmar-al-301xl-12_M.pdf` — AL301XL platform assembly (rocker-to-toggle
  switch change noted in its revision history).
- `Harmar-al-600-12_R.pdf` — the original lead for **AL600** (hybrid
  tower/base assembly, hybrid platform assembly), once thought to be a
  thinly-documented [[AL-Series-Outside-Vehicle-Lifts]] variant. Full
  owner's/install manuals obtained in a later ingest confirmed AL600 is
  actually the flagship model of the separate
  [[Hybrid-Vehicle-Lifts]] line — see that page for the complete
  documentation now on file.

## Hoist lift assemblies (confirms Hoist-series identity)
- `Harmar-al425_N.pdf`, `Harmar-al435_L.pdf`, `Harmar-al825_J.pdf` — AL425/
  AL435/AL825 hoist-lift assemblies, each explicitly listing an "Owner's
  Manual" and "Warranty Sheet" as hardware-pack contents, confirming
  these are the [[Hoist-Series-Inside-Vehicle-Lifts]] models rather than
  Outside Vehicle Lift variants.
