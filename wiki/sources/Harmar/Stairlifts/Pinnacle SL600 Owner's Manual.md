# Pinnacle SL600 Owner's Manual

P/N 76016 Rev H, 10APR26 — note the different part-numbering scheme
(`76016`, not Harmar's usual `6XX-XXXXX`/`610-XXXXX-XX` format used
elsewhere in this batch). Owner's manual for Harmar's **Pinnacle SL600**
straight-rail stairlift, Harmar's **commercial-rated** stairlift: ETL
listed to ASME A17.5-2019/CSA B44.1:19 and ASME A18.1-2020, rated for both
commercial and residential use, and separately FDA-registered (Class II,
510(k) exempt, product code PCD).

## Covers
- 350 lb max payload (vs. SL300's 300 lb)
- Standard Folding Rail (described without an "optional" qualifier, unlike
  SL300's — worth confirming against an install manual if one is ever
  ingested)
- 3-color LED indicator on the armrest (green/amber/red) rather than
  SL300's separate chassis-mounted light — red triggers a self-test
  sequence (red→amber→green) on power cycle
- Manual seat swivel only in this manual (no Power Swivel/Power Footrest
  section — unclear if those options exist for SL600 or just aren't
  documented here)
- Major/minor fault beep-code tables, same scheme as SL300/Helix — see
  [[Harmar-Stairlift-Beep-Codes]]
- **Limited lifetime warranty** on motor/gearbox/worm gear/gear rack + 3yr
  other parts (stronger than SL300's 2yr+10yr-rack) — see
  [[Harmar-Warranty]]
