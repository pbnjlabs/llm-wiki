# Helix Install Manual

P/N 630-00063-01 Rev D, 24SEP2021. First install/service manual on file
for [[Helix]] — closes the "no install manual" gap noted when Helix was
first ingested.

## Covers
- Two-installer, ~3-hour standard install; rail/pipe assembly and
  stair-support placement per a per-job custom drawing
- Battery install (black/red polarity, white jumper between the two
  batteries), chassis install (drive onto gear rack via an install rocker
  switch), seat install, mid-charging-station install
- **Overspeed mechanism — mechanically a jammer, not a centrifugal
  governor**: moving the arm releases a jammer between the gear rack and
  sprocket, and a limit switch cuts power. Reset by pushing the jammer
  back into place. A shipping bolt must be removed before this feature is
  active — see [[Overspeed-Safety-Brake]]
- Wireless remote pairing procedure (hold "pair" button + remote's up
  button 3 seconds)
- Full pre-handoff operational checklist (stops, obstruction sensors,
  final limits, seat swivel sensor, overspeed shipping bolt removed,
  12-hour initial charge)
- Same major-fault beep table (1-9) as the owner's manual — see
  [[Harmar-Stairlift-Beep-Codes]]
- 6-month/annual maintenance checklists (near-identical to owner's manual)
