# Pinnacle SL300 Install Manual (2026, Rev L)

P/N 630-00100 Rev L, 07AUG2026. Current revision of the SL300 install
manual — first install/service manual on file for [[Pinnacle-SL300]]. A
prior revision, Rev K (23JUL2024), is also on file as
`SL300-INSTALL.pdf`; see
[[Pinnacle SL300 Install Manual (2024, Rev K, superseded)]].

## Covers
- Rail-length determination (7'9" standard sections, 3'/5'/7'9" mid
  sections, custom cut), zero-intrusion install option, min/max stair
  angle 30°-45° (up to 52° with a code variance)
- Chassis install onto rail, footrest/seat install (46 ft-lb footplate
  torque), left/right armrest control swap procedure
- **Full folding-rail handing-reversal procedure** (convert a right-hand
  folding rail to left-hand or vice versa — gas-strut/link-arm/fork
  disassembly, ~15+ minutes, trained installer only)
- Remote re-programming, travel-limit setting, safety-stop-switch test
  sequence, seat-swivel lock-angle test (35° and 85°)
- Major/minor fault tables matching the owner's manual (8 major-fault
  codes, no "final limit" code) — see [[Harmar-Stairlift-Beep-Codes]]
