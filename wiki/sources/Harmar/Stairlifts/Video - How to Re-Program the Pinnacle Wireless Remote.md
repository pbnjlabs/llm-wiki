# Video: How to Re-Program the Pinnacle Wireless Remote

Harmar training video #25, 3:20, by a Harmar tech-support presenter.
Pairing call/send remotes to a Pinnacle chassis
([[Pinnacle-SL300]], [[Pinnacle-SL600]]), plus two field tips. No date.

## Pairing

| Time | Step |
|---|---|
| 0:10 | Remotes come **paired from the factory**. Re-pair when you fit a replacement. |
| 0:27 | **Power off** and **unplug the seat and footrest cables**. |
| 0:36 | **Hold the install switch** (the black rocker on top of the chassis) and **turn the power on**. |
| 0:47 | Keep holding until the start-up beep **ends**, then release. The chassis goes into **quick-beep programming mode**. |
| 0:55 | Press the remote. A **double beep** means it's accepted. |
| 1:18 | Power off, plug the seat and footrest back in, power on, and test the remotes. |

## Troubleshooting tips

- **Most common support-line mistake (1:53): letting go of the install
  switch too early.** The chassis then starts normally instead of
  entering the quick-beep programming mode.
- **Is the remote sending? (2:15)** You can't see infrared, so point the
  remote at a **phone camera** (usually the **selfie camera**) and press
  a button. The LED should flash on screen. If it flashes, the remote is
  fine and only needs pairing.

## Checked against the manuals

Matches the remote re-programming section of the
[[Pinnacle SL300 Install Manual (2026, Rev L)]], which adds one rule the
video skips: **program both remotes in the same cycle.** Press the
first remote while pointing it at an IR sensor on the chassis (**1
beep**), then the second (**2 beeps**). The video's "double beep" is
probably the second remote's confirmation. Bruno's
remote and IR-repeater notes are in [[Stairlift-Troubleshooting]].
