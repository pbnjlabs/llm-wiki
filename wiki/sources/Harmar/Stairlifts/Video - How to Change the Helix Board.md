# Video: How to Change the Helix Board

Harmar training video #34, 5:38, by a Harmar Technical Services tech.
Replacing the **main circuit board** (the universal access board) on a
[[Helix]] curved stairlift. No date or board part number.

**Tools:** **anti-static wrist strap** clipped to the chassis, Phillips
screwdriver, **5/16 in socket**, needle-nose pliers.

## Removal

| Time | Step |
|---|---|
| 0:09 | Put the wrist strap on, clipped to the chassis. |
| 0:22 | **Disconnect the battery negative and positive first.** |
| 0:44 | Unplug, in order: **both IR sensors**, the **diagnostics** lead, **charging C− / C+**, **motor M1 / M2**, **battery B− / B+**, **brake BK1 / BK2**. |
| 1:25 | Unplug the **30-pin connector** and take the board out. |
| 1:33 | Remove the **heat sink** (two 5/16 in nuts and Phillips screws) and set the old board aside. |

## Installation

| Time | Step |
|---|---|
| 2:14 | Fit the heat sink to the new board. |
| 2:32 | **Connect the 30-pin connector before mounting the board.** |
| 3:04 | Mount the board on the chassis. |
| 3:43 | Reconnect: diagnostics, IR sensors, C+ / C−, **M2 = black motor lead, M1 = red motor lead**, B− / B+, BK1 / BK2 (brake leads). |
| 5:15 | Reconnect the battery. |

## Checked against the manuals

There's no board-replacement procedure on file. The [[Helix Install Manual]] warns that **reversed battery wiring can damage the universal
access board**, so check the battery and B± polarity before powering up.
Write the terminal labels down (or photograph them) before unplugging.
Test with [[Video - Helix Curved Stairlift Diagnostic]] afterwards.
