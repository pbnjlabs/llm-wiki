# SRE-3050 Operator Manual (Elan)

14-page end-user manual, P/N 3050-O.

Key content:
- **Not recommended for**: scoot-pivot transfers from a wheelchair without
  leg weight-bearing, or users with leg weakness/uncontrolled knee-buckling
  during stand-to-sit transfer. Bruno explicitly directs these users to the
  [[SRE-2010]] Elite instead.
- Specs: 300 lb capacity, constant-pressure control (armrest + 2 IR
  remotes), 45° max incline (52° special order), seat swivel 0/67/90°,
  24VDC battery charger (120VAC/60Hz/0.35A in, 1A out, continuous
  monitoring)
- Safety features: obstruction sensors on footrest, overload sensors on
  power swivel seat and power footrest (jam → return to last position),
  power folding rail current-overload sensing
- Seat: 3 lock positions (home, 67°, 90°); optional power swivel seat
  (re-engage armrest paddle in same direction after stop to swivel)
- Optional power footrest: folds automatically when seat raised to stored
  position — never fold manually, it can damage the unit
- Manual and power folding rail operation (mid-travel stop position logic,
  disable switch, obstruction reverse-and-stop behavior) — see
  [[Folding-Rail]]
- Troubleshooting: multi-user mode beep-at-top-when-seat-rotated is normal
  (dealer can switch to single-user mode to silence it); slow operation /
  won't-operate decision tree keyed to charger LED color
- Warranty: Bruno Gold — lifetime on major components (motor, gearbox,
  drivetrain, static rail), 2 years parts, 30 days labor from install date
