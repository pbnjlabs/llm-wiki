# Tech Tip - SRE-3000 Temperature Range

1-page Bruno position (article 107, modified 3/28/2014; portal tech-tip 180): the Elan must be used **above 35 °F**, as its manual says ([[SRE-3000 Installation Manual]]; the [[SRE-3050 Install Manual]] says the same: indoor only, enclosed heated locations above 35 °F / 2 °C).

Added rule: **Bruno treats a garage as exterior** unless it's completely climate controlled (summer humidity is higher without air conditioning). So no Elan in an ordinary garage.
