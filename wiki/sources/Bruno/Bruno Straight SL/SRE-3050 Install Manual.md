# 3050-I SRE-3050 Install Manual (Elan)

28-page dealer installation manual, P/N 3050-I.

Key content:
- Site review, rail measurement formula (stair length + seat-height offset;
  add nose-to-door + 3" for obstacles at top), rail cutting rules (never
  shorter than 24"/610mm; cut at least 12" off one rail when splitting
  length across two rails)
- Rail mount density: min. 2 rail mounts per rail section in multi-rail
  jobs, min. 3 in single-rail runs, no more than 4 steps in a row without a
  mount; adjustable rail mounts (SRE-30150WG) for overhangs >6"
  horizontal/12" diagonal past the top step nose
- Lower/upper rail prep (charge strip carrier, slow-down contact, joint
  brackets/pins, nut bars), rail installation torque specs (25 ft-lb rail
  mount hardware, 22 ft-lb endplate screws)
- Carriage installation incl. left/right-hand conversion (jumper on
  circuit board, sensor connector re-routing) and overspeed-gear alignment
  cautions during carriage-onto-rail jogging — see [[Overspeed-Safety-Brake]]
- **Rail Cross Pin Installation** — a drilled safety pin through the rail
  extrusion near the bottom gear rack tooth, using a supplied drill
  template (Bruno kit SRV-3000-023) — not mentioned in the older
  [[SRE-3000]] manual, likely a newer safety addition
- Footrest and seat installation, charger connections, gear rack
  lubrication (PTFE, gear rack only)
- Multi-user → single-user diagnostic mode switch, full audio diagnostic
  code table (same codes as [[SRE-3050 Operator Manual]]/[[SRE-3050 Tech
  Support Guide]])
- Installation checklist (final walk-through items)
- Exploded view: confirms "Elan" branding, folding rail options
  (SRE-K-3064/3065/3072 kits), power swivel seat assemblies
