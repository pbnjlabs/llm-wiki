# 2010-TS Tech Support Guide (SRE-2010)

86-page field service guide for the SRE-2010 "Elite" straight-rail stairlift
(residential units only). Covers the SRE-2010, SRE-2010C, SRE-2010OS,
SRE-2010CAN, SRE-2010G, SRE-2010E/EOS variants.

Contents:
- Technical specifications (ILS-00826) — see [[SRE-2010]]
- Carriage adjustments: drive adjustment (rack/pinion vibration), carriage
  angle adjustment, overspeed reset for both cam-style (2010C/2010OS) and
  cover-style (2010EC/EOS) carriages — see [[Overspeed-Safety-Brake]]
- Seat adjustments: swivel stop position, multi-user vs single-user
  diagnostic mode (DIP switches), arm extension (two hardware generations:
  pre- and post-October 2022), seat switch changeover (paddle switch to
  opposite armrest)
- Remote programming: reprogramming IR remotes via SW3 DIP switch + circuit
  board LEARN/ERASE button
- Troubleshooting chart, code translations (A1-A8, C1-C6, D1-D8, L1-L8,
  O1-O5, P0-P9 diagnostic codes), diagnostic code table (cross-references
  segment/beep patterns), battery charger LED table
- Opposite-hand conversion (SRE-2010/2010E) — 36-page, ~35-step full field
  procedure to flip the seat swivel plate, carriage, footrest, and rewire
  for the opposite side of the stairs
- Rail mounting guidance (ILS-01512) — construction-type-specific anchoring
  guidance (wood, hardwood, engineered wood, marble/tile, steel, poured
  concrete, precast, cinder block, railroad ties, glass) — **identical
  document also embedded in the [[SRE-3050]] tech support guide**, see
  [[Rail-Mounting-Guidance]]
- Power folding rail: gear rack replacement, joint adjustment, greasing,
  drive adjustment — see [[Folding-Rail]]
- Wiring schematics (pp. 45-51) and exploded parts views (pp. 52-86, not
  itemized in this wiki — reference the PDF directly for part numbers)
