# SRE-3000 Installation Manual (Elan)

78-page dealer installation manual, P/N 3000-I, dated 2015 — the oldest and
least-current document in this cluster. Title page reads "SRE-3000 ELAN
STRAIGHT RAIL STAIRLIFT INCLUDING FOLDING RAIL," confirming [[SRE-3000]]
and [[SRE-3050]] share the "Elan" product line branding; the SRE-3050
install manual is this document's successor (same architecture, updated
2026 hardware/procedures).

Key content:
- Specs: 300 lb capacity, 18 ft/min max speed, 24VDC 2-pole 50Nm motor,
  rack-and-pinion drive, 1Nm electromechanical motor brake, 45° max incline
  (52° special), seat swivel 0/67/90°
- Rail lengths: "new" nominal-vs-actual length tables (8'/10' sections,
  16'/18'-folding-only/20' full lengths) — note the 18' folding-only length
  option
- Full rail prep, joint, folding-rail, carriage (LH/RH conversion), seat,
  and finishing procedures — near-identical structure/figures to the later
  [[SRE-3050]] install manual, confirming continuity of the platform
- Circuit board diagnostics: 4-mode audio diagnostic system (multi-user vs
  single-user), same chirp/beep code language reused in later SRE-2010 and
  SRE-3050 docs
- IR remote transmitter learning (DIP switch SW3 + LEARN/ERASE button) —
  same mechanism as [[SRE-3050]]
- **Overspeed** section (reset procedure, regulatory test procedure) —
  same content/figures as later SRE-2010/SRE-3050 docs, see
  [[Overspeed-Safety-Brake]]
- Maintenance schedule, battery removal/reinsertion, wiring schematic,
  troubleshooting chart
- Exploded views (pp. 47-76, not itemized here) and limited warranty (p.77)
