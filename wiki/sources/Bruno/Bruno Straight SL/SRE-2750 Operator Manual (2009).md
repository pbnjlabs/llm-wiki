# SRE-2750 Operator Manual (Electra-Ride LT, 01-14-2009)

Owner's manual for the legacy **SRE-2750** (22 pages).
- **Specs:** swivel 0°, 67° and optional 90° (or a combination) in both
  directions. Capacity per the install manual is 275 lb.
- **End charging:** park against the upper or lower charge bracket, or
  the batteries drain.
- Charger LED table, transmitter care, storage and
  troubleshooting follow the [[SRE-2000 Operator Manual (2007)]].
