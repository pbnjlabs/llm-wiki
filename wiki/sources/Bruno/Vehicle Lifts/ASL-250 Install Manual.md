# ASL-250 Install Manual (2019)

P/N 250-I, 03-12-2019. Install manual for Bruno's **Out-Sider**
(ASL-250) and **Out-Sider with Swing-Away** (ASL-250HTP configurations
included) hitch-mounted vehicle lift — the **older hardware generation**
predecessor to [[ASL-275]] (2026 manual on file). Same "Out-Sider"
branding as ASL-275, but a materially different platform lineup and
hitch-height-adapter table — see [[ASL-250]] for the full comparison.

## Key content
- 350 lb max capacity, Class II/III hitch, not RV-compatible — same
  headline specs as ASL-275
- Three platform families: 3-piece adjustable (scooters/power chairs,
  Hold-Tite foot or retractable belts), modular (power chairs only), and
  **HTP** (ramped platform with FWD/RWD/MWD chock-plate driving
  configurations and its own pivot-arm hold-down setup) — HTP is not
  mentioned anywhere in the ASL-275 documentation on file
- Installed weight 85-110 lb (without Swing-Away) — lighter than
  ASL-275's 110-125 lb
- Height-adjustment table gives a narrower standard range (12"-19"
  without Swing-Away, 9"-17" with) than ASL-275's single "6"-24" via 3
  adapters" statement, with optional adapters extending to 7"-25"/7"-23"
- Confirms the inline fuse at the battery is specifically an **ATO 30A**
  fuse (clarifies the "30A" fuse type left ambiguous on [[ASL-275]] and
  in [[Vehicle-Lift-Power-Wiring]])
- Wiring diagram (Bruno PCB-00160) shows integrated trailer-lighting
  pass-through (brake lamp, license plate lamp, turn signals via a 4-flat
  or 7-pin connector) sharing the same PCB as the lift actuator circuit
- Warranty text is word-for-word the Bruno Gold vehicle-lift warranty
  (3yr all parts, rev. 01-16) — identical to [[PUL-1100]] and
  [[ASL-275]], see [[Warranty]]
