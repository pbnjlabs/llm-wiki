# ASL-700 Installation Manual (2025)

28-page install manual (P/N 700-I, 01-14-2025) for the **ASL-700 Chariot**, a wheeled hitch-mounted platform lift (350 lb, Class I/II 1.25 in hitch, own tires and lights, VIN).
