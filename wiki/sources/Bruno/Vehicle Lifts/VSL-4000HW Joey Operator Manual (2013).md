# VSL-4000HW Hardwire Joey Operator Manual (09-15-2013)

Owner's manual for the legacy **VSL-4000HW** Joey (20 pages). It covers
loading and unloading, the pendant and door switch interlock (it won't
run with the door closed), and the emergency backup with the tools under
the shroud. Yearly dealer service. The service detail is in the
[[VSL-4000HW Joey Installation Manual (2017)]].
