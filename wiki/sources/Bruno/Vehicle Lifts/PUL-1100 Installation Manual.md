# 1100-I Installation Manual (PUL-1100 Out-Rider)

32-page install manual for the PUL-1100 "Out-Rider" — a pickup-truck-bed
mounted lift that swings a wheelchair/scooter from ground level up and over
the truck bed side wall for storage (not a rider lift; it moves the empty
mobility device, not a person). Load ratings: 100 lb (light-duty actuator),
200 lb (standard), 350 lb (heavy-duty motor).

Contents:
- CE/max load rating table
- Base assembly installation (bolts through truck bed floor, with/without
  bed liner variants), lift-onto-base assembly, offset arm installation
- Power cable routing from vehicle battery through firewall to lift,
  including a hybrid/EV note (locate the 12V accessory battery, not the
  traction battery) — see [[Vehicle-Lift-Power-Wiring]]
- Control box, motor harness, and pendant magnetic-holder installation
- Limit switch wiring/adjustment (2 cams: IN/OUT stop, driver vs. passenger
  side wiring differs — see model page for the cam rotation table)
- Bruno control board adjustment (acceleration/deceleration/speed per axis:
  hoist, in/out, ext/ret motors)
- Fitting the lift to the mobility device (docking device height/clearance
  procedure, white sight-line stitching reference mark)
- Loading/unloading procedures (hand pendant control)
- Emergency operation: hand crank on motor shaft (return-to-vehicle only,
  not full operation)
- Wiring schematic, troubleshooting chart, exploded views/BOM (pp. 29-31,
  not itemized here — reference the PDF for part numbers)
- Bruno Gold Limited Warranty for Vehicle Lift (3 years) — see [[Warranty]]
