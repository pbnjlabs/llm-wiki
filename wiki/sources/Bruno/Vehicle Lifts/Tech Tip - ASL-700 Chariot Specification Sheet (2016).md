# Tech Tip - ASL-700 Chariot Specification Sheet (2016)

1-page Bruno spec and measurement sheet for the **ASL-700 Chariot** (2016-12-14; portal tech-tip 190, and 200 by mistake).

| Item | Value |
|---|---|
| A. Hitch height range | 8–16 in |
| B. Bumper to chassis (minimum clearance from the vehicle) | 6.5 in |
| C. To end of platform, loading position on the ground | 74.5 in |
| D. To end of platform, travel position | 50.5 in |
| E. To fender edge, platform folded, caster trailing | 34.5 in |
| Max mobility device | **350 lb**, 27 in wide, 38.5 in wheelbase |
| Unit weight / tongue weight | about **340 lb** / about **50 lb** |
| **Minimum vehicle weight** | **2,400 lb** |
| Hitch | Class I or II, 1¼ in receiver, **frame-mounted only** (trunk-pan/floor hitches damage the vehicle) |
| Wiring | **Flat-4** trailer connector required |

**Conflict:** the sheet says a **2 in** receiver can be used with hitch adapter kit **ASL-K-707**. The current [[ASL-700 Installation Manual (2025)]] says **1¼ in Class I/II only**. The manual wins; ask Bruno before using a 2 in hitch.
