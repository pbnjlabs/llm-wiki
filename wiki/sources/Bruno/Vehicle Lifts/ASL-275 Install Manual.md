# 275-I Installation Manual (ASL-275 Out-Sider / Out-Sider with Swing-Away)

42-page install manual for the ASL-275 "Out-Sider" — a hitch-mounted
platform lift for scooters/powerchairs, optionally with a Swing-Away arm.
Max lifting capacity 350 lb (159 kg). Not compatible with RVs (motorhomes,
buses, fifth wheels, travel trailers).

Contents:
- Technical specs: platform styles (standard scooter, standard powerchair,
  standard lightweight powerchair, large scooter), hitch compatibility
  (Class II 1.25" / Class III 2"), height adjustment range (6"-24" hitch
  interface)
- Safety/hardware notes: tongue-weight-rating math (TWR − lift weight = max
  mobility equipment weight, capped at 350 lb), anti-seize/Loctite guidance
  for stainless hardware, warning not to pneumatic-tighten (self-welds),
  disable touchless tailgate before install
- Power wiring: route from vehicle battery through a 30A fuse to the lift,
  same firewall/routing pattern as PUL-1100 — see
  [[Vehicle-Lift-Power-Wiring]]; optional 7-pin trailer connector kits
  (INS-K-2002/2003)
- Installation steps 1-10: measure hitch height → choose hitch adapter
  (Standard/3"/6" offset, from a height-to-adapter-position lookup table)
  → apply Magnalube → mount adapter → level the mast (90° to ground) →
  install Swing-Away (if equipped) → connect harnesses → adjust Swing-Away
  height via the swing-arm adjustment screw
- Platform adjustments: scooter wheel-chock spacing table and powerchair
  wheel-chock spacing table (both by wheel diameter), Hold-Tite foot/arm
  securing procedure, optional retractable belt kit
- Complete-installation checklist (clearance for tail/brake/turn
  lights, license plate visibility — includes a license-plate-extension
  procedure), optional third brake light kit
- Maintenance (semi-annual: keyswitch/switch/brake-light checks, re-grease
  telescoping tubes with Magnalube, platform tilt angle 3-6°)
- Emergency operation: hand crank on motor shaft, clockwise=raise/
  counterclockwise=lower (3/8" electric drill also usable)
- Wiring diagram, troubleshooting chart (electrical fault isolation via
  circuit board KEY/UP/DOWN jumper tests), exploded views/BOM (pp. 22-42,
  not itemized here)
- Bruno Gold Limited Warranty for Vehicle Lift (3 years, identical text to
  PUL-1100's) — see [[Warranty]]
