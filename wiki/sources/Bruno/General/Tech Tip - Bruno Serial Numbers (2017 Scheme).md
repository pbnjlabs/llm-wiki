# Tech Tip - Bruno Serial Numbers (2017 Scheme)

1-page Bruno reference (2018; portal tech-tip 194) to the **11-digit serial**, with an updated product list. Example **17090330203**: 1709 = September 2017; 033 = product group 03 (accessibility) and model 3 (Elan); 0203 = the 203rd unit that month.

| Code | Product |
|---|---|
| 032 / 033 / 034 / 035 | Elite (SRE-2010) / Elan (SRE-3000) / Curve (CRE) / VPL (all) |
| 011 | Rear hoist (VSL-570, PUL-1100, VSL-6000, VSL-6900) |
| 012 | ASL-250 |
| 013 | Swing-away |
| 014 | Interior lift (VSL-4400) |
| 015 | VSS turning seats (TAS-2402E, TAS-2570E, TAS-5301, VSS-2602) |
| 016 | Light exterior (ASL-225, AWL-1600) |
| 017 | Manual trunk lift (ASL-150, ASL-325) |
| 018 | Under-vehicle seating (PUL-1850) |
| 060 | Chariot (ASL-700) |
| 040 / 050 | New / refurbished replacement part |
