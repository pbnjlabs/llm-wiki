# Tech Tip - Stairlift Grease Specifications

1-page note from Bruno engineering (portal tech-tip 181). Bruno tested greases for its stairlifts and recommends two, both **Lubriplate**:
- **130-AA:** what Bruno shipped with each unit. Dropping point 200 °F (93 °C).
- **630-AA:** for **higher-temperature** applications. Dropping point 380 °F (193 °C).

Older note. The current manuals name different greases (see [[Stairlift-Maintenance]]).
