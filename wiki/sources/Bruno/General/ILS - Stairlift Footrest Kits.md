# ILS - Stairlift Footrest Kits

Footrest sheets.
- **ILS-01069 SRE-K-3027 (2014) and ILS-01424 SRE-K-3060 (SRE-3050), armrest-mounted power-footrest fold switch:** move the paddle switch to the LH side first if wanted (can't later); cut the red and green wires of that armrest's harness at the connector, crimp quick-disconnects, fit the rocker (white dot / red wire up), connect to the two orange flag terminals on the power-footrest swivel harness, heat-shrink. Start with the switch **down** so the footrest doesn't fold at power-up. On the SRE-3050 it goes in the arm **opposite the paddle**.
- **ILS-00856, wide footrest (SRE-2010)** and **ILS-00867 (2009), wide power footrest:** swap the pan on the seat post; gas spring with the tool provided; Bruno doesn't recommend the standard lever on the wide footrest (if used, secure it). Power version: set the **aux PCB switch position 1 ON**.
- **ILS-01533 (10/11/22), Elite footrest handle:** a **manufacturing defect** can make the joint between handle SRE-20568 and lift link SRE-20967 tight, which can crack the link. Replace the handle and the link (even if not broken); shoulder bolt to bottom out with the link still swinging free; loosen the far nut slightly so it pivots.
