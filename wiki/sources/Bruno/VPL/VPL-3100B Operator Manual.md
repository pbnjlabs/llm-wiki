# VPL-3100B Operator Manual

32-page end-user operator manual, trilingual (English pp.1-10, Spanish
pp.11-19, French pp.21-29 — content identical across languages, only read
the English section in full).

Covers: specs (matches the [[VPL-3100B Install Manual]]), safety, operating
instructions (open gate → board → lock mobility-device wheels → key ON →
rocker switch up/down → key OFF → exit), cold-weather operation, emergency
operation (hand wheel only), battery charger LED diagnostic chart (same
table as the install manual — see [[Battery-Charger-LED-Diagnostics]]),
basic troubleshooting, maintenance schedule, warranty.

No content here beyond what's already captured from the install manual —
this is the customer-facing subset. Feeds: [[VPL-3100B]]
