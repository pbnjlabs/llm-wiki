# Tech Tip - VPL Platform Control Change (2011-2012 Serials)

2-page Bruno reference (portal tech-tip 133) giving the **serial numbers where the platform controls changed**, with the old and new control part numbers (photos):

| Model | First change (old controls VPL-31908/31915/31916/31917) | Second change (about 3/5/2012; VPL-31686/31696 → VPL-31681/31683/31956/31957) |
|---|---|---|
| VPL-3153 | 11110300143 | 12070300108 |
| VPL-3175 | 11110300139 | 12070300111 |
| VPL-3153B | 11110300162 | 12070300110 |
| VPL-3175B | 11110300170 | 12070300109 |
| VPL-3210B / 3212B / 3214B | 11110300112 (all) | 3210B 12070300097, 3212B 12070300112, 3214B 12110300156 |

The sheet prints "VPL-3121B"; that's the 3212B. The **second set of serials is the same cutoff** TechMate uses for its supported boards and the Waupaca wiring-kit change, so **July 2012 (12 07 …)** is the big control change for low-rise and tall residential VPLs.
