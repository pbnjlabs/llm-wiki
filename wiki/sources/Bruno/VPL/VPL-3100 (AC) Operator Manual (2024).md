# VPL-3100 (AC) Operator Manual (09-16-2024)

Owner's manual for the AC **VPL-3153 / VPL-3175** (8 pages). It is the
same text as the [[VPL-3100B Operator Manual (2024)]], minus the battery
material:
- Keyed constant-pressure rocker; lock the chair's wheels.
- Park it mid-way when not in use.
- **Below 0 °F:** clear ice and snow, then run down, up, and board. **No
  salt near the lift.**
- **Emergency:** hand wheel only (no battery backup).
- Yearly dealer inspection.
