# Tech Tip - Code Requirements for Door Interlocks

1-page excerpt (portal tech-tip 119) of the platform-lift code (ASME A18.1 numbering; the sheet doesn't name the edition, and **its text is cut off at the right margin in Bruno's own PDF**). Section 2 (commercial, runway enclosure 2.1.1 and partial enclosure 2.1.2) sets the door and interlock rules; **Section 5 (residential) refers back to Section 2**.

2.1.1.4, as far as it's legible: every door needs a **combination mechanical lock and electric contact**, protected against tampering from the landing side; the lock may release only with the **platform floor within 2 in (50 mm) of that landing**; the platform may leave the landing with the door closed but not locked as long as it **stops if it moves more than 2 in away before the door locks**; and doors take **125 lbf on any 4 x 4 in area** without permanent deformation.

For the full rule, use the current A18.1 text. See also [[ADA-Ramp-Requirements]] for the access-board context.
