# ILS - VPL Application Drawings

Bruno's **technical (application) drawings** for each VPL layout: platform and tower dimensions, minimum slab size and anchor locations, floor-to-floor ranges and running clearances. The dimensions are in drawing tables. **Open the PDF for the job's layout.** Every sheet repeats the same notes: 750 lb rated load; AC 9 ft/min, DC 10 ft/min; a **4 in, 3500 psi reinforced slab**; **four ½ in (3/8 in bolt) × 2½ in min anchors**.

| Line | Layout | Sheets |
|---|---|---|
| VPL-3100 (older) | standard straight-through; 48 in platform | ILS-00803 (2009), ILS-00833 (2008) |
| VPL-3100 / 3200B, **unenclosed** | straight-thru, 90°/adjacent exit, no pit / pit with platform gate | ILS-00932–00935 (10/15/21); **residential versions ILS-01557–01560 (11/03/22)** |
| VPL-3100 / 3200B, **hoistway** | straight-thru, 90°, same side (3200B), no pit / pit | ILS-00980–00985 (2018) |
| VPL-3300B commercial, unenclosed | with platform gate, no pit / pit | ILS-01102–01105 (10/15/21) |
| VPL-3300B commercial, hoistway | straight-thru, 90°, same side | ILS-01176–01179, ILS-01253/01254 (2018) |
| VPL-3353B, enclosed | straight-thru with 3 gates | ILS-01154/01155 (2018) |

- **Hoistways must be plumb within ±1/8 in** because the running clearances are tight (hoistway drawings).
- Access ramp (and platform gate) can mount on either side of the platform.
- Pit applications: maximum floor-to-floor is measured from the **bottom of the pit** to the upper landing.
