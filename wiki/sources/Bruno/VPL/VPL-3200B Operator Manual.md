# VPL-3200B Operator Manual

20-page end-user operator manual, bilingual (English pp.1-10, French
pp.1-10 duplicated — identical content).

Covers: specs (model VPL-3210B, matches the [[VPL-3200B Install Manual]]),
safety — including a flood-zone note ("will not operate if there is more
than 3\" of standing water at the base"), operating instructions (same
flow as [[VPL-3100B]]: gate → board → lock wheels → key ON → rocker switch
→ key OFF → exit), cold-weather operation, **emergency operation covers
both the electrical emergency-lowering key switch and the manual hand
wheel** (the 3100B operator manual only documents the hand wheel), battery
charger LED diagnostic chart (see [[Battery-Charger-LED-Diagnostics]]),
troubleshooting, maintenance, warranty.
