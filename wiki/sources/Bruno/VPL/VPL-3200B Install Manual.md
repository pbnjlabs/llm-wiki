# VPL-3200B Install Manual

76-page installation manual for the VPL-3200B (model number VPL-3210B) —
Bruno's larger vertical platform lift, built for multi-floor hoistway
installs (max floor-to-floor 123"/3.1m, vs. the [[VPL-3100B]]'s 53"/75").

Contents:
- Specs, tools, torque, hardware quick-reference guide (pp.5-6) — see
  [[VPL-3200B]]
- Safety, pre-installation checks (hoistway-specific: flush-mounted door or
  60° deflector shield, walls no more than 1/8" out of plumb), job site
  prep (pp.7-10)
- Tower installation: shipped as **two half-towers** joined on site with a
  hoist — uncrating, bottom section, mounting top section, **coiled spring
  pin installation** joining the two drive-screw halves (align red marks,
  press pins to controlled depth with a supplied tool, apply retaining
  compound) — a much more involved assembly than the 3100B's single-piece
  tower (pp.11-16)
- Mounting back/side panels, electrical wiring, top cover safety switch
  (pp.16-20)
- Top Landing Gate installation — EMI, ESI, 42" high, wide (90°) gate,
  cam/activator adjustment — **identical content to the
  [[VPL-3100B Install Manual]]** — see [[Top-Landing-Gate-Installation]]
  (pp.21-37)
- Adjusting upper limit switch (p.37)
- Electrical: wiring call/send and gate, mounting call/send box, PCB-00164
  electrical enclosure layout and indicator-light board (pp.38-41)
- Securing the unit and testing (p.42), front covers/telescoping pole
  assembly (p.43)
- Moving ramp/ramp activator/vertical bar to opposite side (pp.44-46)
- **Emergency lowering operation** — this model has an electrical emergency
  lowering kit (keyed switch, mounted *outside the hoistway* at the lower
  landing, AUTO/OFF/LOWER) in addition to the manual hand wheel — the
  3100B only has the hand wheel (p.47) — see [[VPL-3200B]]
- Cold weather operation, disconnecting/locking out multiple power sources
  (p.48)
- Changing the batteries — main 2×34AH pair plus a separate emergency
  lowering battery (12VDC, 7.5AH, Bruno part BTR-12002) (pp.49-50)
- Battery charger LED diagnostic chart (p.51) — **identical to the
  [[VPL-3100B Install Manual]]** — see [[Battery-Charger-LED-Diagnostics]]
- Preventive maintenance (p.52, identical content to 3100B)
- Troubleshooting table + PCB-00164 indicator-light diagnostic guide
  (no-lights/4-LEDs/top-landing/bottom-landing/up/down states) (pp.53-55)
- Wiring schematics (pp.56-59), exploded views (pp.60-75, not itemized
  here)
- Bruno Gold Limited Warranty (p.76, identical terms to 3100B)
