# Tech Tip - VPL Traveling Cable Assignments

1-page Bruno table (portal tech-tip 139) of the **travelling cable** wire numbers and colours across the low-rise residential, low-rise commercial and tall residential lines (the right-hand column is cut off in the PDF). Old number → colour → use:

| Old | Colour | Use |
|---|---|---|
| BLK1 | Red | Platform controls, keyed power |
| BLK2 | White | Platform controls up |
| BLK3 | Black | Platform controls down |
| BLK4 | Orange | E-stop in |
| BLK5 | Brown | E-stop out / nut safety switch |
| BLK6 | Blue | Platform controls ground |
| BLK7 / BLK8 | Yellow / Violet | Safety pan |
| BLK9 / 10 / 11 | Gray / Pink / Tan | Platform gate |
| BLK12 | Red/green | Platform controls mid (commercial) |
| BLK13 | Red/yellow | Platform aux power (commercial) |
| BLK14 / 15 | Red/black, white/green | Phone line |
| BLK16 / 17 | White/red, white/black | Phone power +24 V / ground (commercial) |
| — | Yellow/green | Chassis ground |

12-conductor cable on residential units (an extra 4-wire cable is added where needed). Matches the JP3 colours on [[VPL-Troubleshooting]].
