# VPL-3100B Install Manual

61-page installation manual for the VPL-3100B battery-operated vertical
platform lift (models VPL-3153B, VPL-3175B — differ by max floor-to-floor
height: 53" vs 75", i.e. essentially a single-floor porch/deck lift).

Contents:
- Specs, tools, torque (p.5) — see [[VPL-3100B]]
- Safety, pre-installation checks, job site prep (pp.6-9)
- Main component/tower assembly, securing unit, adjusting top landing/final
  limit switches (pp.10-11)
- Top Landing Gate installation — EMI style, ESI style, 42" high, wide
  (90°) gate, cam/activator adjustment (pp.12-27) — **identical content,
  word-for-word, also appears in the [[VPL-3200B Install Manual]]** — see
  [[Top-Landing-Gate-Installation]]
- Platform gate extension foot (p.28)
- Wiring call/send and gate, mounting call/send box (pp.29-30)
- Testing the unit — underside panel sensors, top housing cover sensor,
  final limit switch, door/gate interlock, platform key switch, call/send
  controls, E-Stop check (p.31)
- Moving ramp/ramp activator/vertical bar to opposite side (pp.32-34)
- Emergency and cold-weather operation — hand wheel only, no electrical
  emergency lowering kit on this model (p.35) — see [[VPL-3100B]]
- Changing the batteries — 2×17AH standard / 2×34AH optional (pp.36-37)
- Battery charger LED diagnostic chart (p.38) — **identical table also in
  the [[VPL-3200B Install Manual]] and both operator manuals** — see
  [[Battery-Charger-LED-Diagnostics]]
- Troubleshooting table (pp.39-40)
- Preventive maintenance (Acme screw/drive nut lubrication, belt/bearing
  checks) (p.41)
- Wiring schematics (p.42), exploded views (pp.43-60, not itemized here —
  reference PDF directly for part numbers)
- Bruno Gold Limited Warranty — 2yr major components / 1yr parts (p.61)
