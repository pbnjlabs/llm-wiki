# CRE-2110 Install Manual

60-page installation manual for CRE-2110/CRE-2110C custom curved-rail
stairlift.

Contents: regulatory info, carton contents/tools, clamp placement and
custom rail installation (numbered rail sections, angle checked every 2ft
against job-specific elevation drawings), zero-degree slope adjustment
(factory-set, do not touch), carriage/footrest/seat installation, final
limit/end cap/charge contact install, overspeed reset (commercial units
only — two-lever procedure, see [[Overspeed-Safety-Brake]]), battery
charger mounting + LED table, rail lubrication, call/send transmitter
mounting/testing, circuit board diagnostics (4 modes) and diagnostic code
table (see [[Diagnostic-Codes]]), circuit breaker, adjustments (footrest
height, charge contact position, seat swivel stop, arm extension),
maintenance/yearly checklist, wiring diagram, exploded views (parts), and
the Bruno Gold Limited Warranty (verbatim match to the standalone
`Bruno Stair Lift Warranty.pdf` — see [[Warranty]]).
