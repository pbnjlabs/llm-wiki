# 2110-TS Tech Support Guide (CRE-2110)

64-page field service guide for the CRE-2110 Elite Curve stairlift.

Contents: technical specifications (ILS-00905), seat adjustments
(multi/single-user mode, arm extension, seat swivel stop, seat switch
changeover — same procedures as [[SRE-2010]]), remote control
learning/programming (incl. optional IR/RF repeater kit CRE-K-2147 for
multi-unit installs), troubleshooting (code translations + diagnostic code
table — see [[Diagnostic-Codes]]), battery charger LED info, circuit
breaker, and rail mounting guidance (the "SRE-2010 Model Rail Mounting
Guide" — identical cross-model document, see [[Rail-Mounting-Guidance]]).
Remaining pages (27-64) are wiring schematics/exploded views not itemized
here.
