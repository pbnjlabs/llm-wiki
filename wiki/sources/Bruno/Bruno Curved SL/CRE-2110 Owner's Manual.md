# CRE-2110 Owner's Manual (2110-O, 06-01-2026)

Owner's manual for the **Elite Curve indoor** (CRE-2110 and OS, 11
pages). The back pages still carry an 11-15-2023 footer.

**Specs:** 400 lb, **45° maximum**, swivel stops 0°, 60° and 90° at the
top. The seat swivels 135° in total, and some installs allow 45° at the
bottom. RF remotes (XBee).

**Operation:**
- Key OFF disables the unit and the remotes.
- **The remote call/send may not work in a power outage**; the seat
  controls still do.
- **Power swivel:** at the top, release and press again.
- **Power footrest** follows the seat.
- **Mid-park option:** it stops and beeps at mid-park and **charges
  there**. Press again to go on.

**Charging (end charge):**
- It charges **only parked tightly against the end brackets** (or
  mid-park).
- A **yellow LED on the charge bracket** shows correct parking.
- **It beeps if stopped short of the charge position.**
- If a door blocks the end, send it with the remote.

**Codes under the seat:**

| Code | Meaning |
|---|---|
| **A6** | Seat jammed |
| **A7** | Footrest jammed |
| C1, C2 | Charging, off charge |
| **C3** | Off charge, not parked |
| C4 | No charger |
| C5, C6 | Battery critical, battery low |
| L1–L3 | Seat safety, up limit, down limit |
| L6 | Mid-park |
| L8 | Soft stop |

The charger LED table is the same as the Elite's.

**Owner care:**
- Remotes take 2 AA, yearly. Yearly dealer service.
- After storage, **turn on the charger's own power switch**.
- Troubleshooting:
  - Multi-user beeping, or beeping when stopped short of the charge
    position.
  - A slow lift: park it at an end to charge.
  - The paddle, the charger LEDs, and the **IR receivers plugged in** if
    the remotes don't work.
