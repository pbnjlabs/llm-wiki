# CRE-2100 Operator Manual (Electra-Ride III, 01-14-2009)

Owner's manual for the legacy **CRE-2100** curve (20 pages).
- **Specs:** **350 lb**, **45°**, swivel 0°, 30°, 60° and 90° in both
  directions at the top and bottom. The speed is dealer-adjustable.
- **End charging:** a **yellow LED on each charge bracket** shows
  contact. If it can't park at an end, send it there with the
  transmitter.
- Charger LEDs, transmitter battery, storage and troubleshooting match
  the other Electra-Ride manuals ([[SRE-2000 Operator Manual (2007)]]).
