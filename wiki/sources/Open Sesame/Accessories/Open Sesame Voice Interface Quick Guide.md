# Open Sesame Voice Interface Quick Guide

2-page setup guide (firmware 3.02.02, 2025) for the **Voice Interface**.
It's an Alexa-enabled Wi-Fi switch, made by MiniTech, that opens the door
through a built-in RF remote. **No Alexa skill or hub is needed.** Works
with 2nd–4th generation Echo devices.

1. Program it like a remote: press the operator's red button, then within
   15 s hold the Voice Interface's red button for 1 s and press it again.
   The door opens if it worked.
2. On a phone, join the Wi-Fi network **"OS WiFi Switch 3.02.xx"**
   (password **sesame911**) and choose "Configure WiFi".
3. Pick the home network and enter its password (case-sensitive). You can
   rename the default phrases "open sesame" and "park open sesame" here.
4. **Required:** wait for the blue LED to flash every 3 s, then unplug the
   Voice Interface and plug it back in.
5. Say "Alexa, discover new devices". Then "Alexa, activate open sesame"
   runs open-wait-close, and "park open sesame" opens the door and holds it.

**More than one door:** set up one Voice Interface at a time, and give
each its own phrases before Alexa discovers it. Alexa keeps the old name
even after a rename.
