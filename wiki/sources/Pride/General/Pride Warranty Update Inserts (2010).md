# Pride Warranty Update Inserts (2010)

Three product inserts (Nov–Dec 2010) that **replace the warranty in
the owner's manual** of the chairs named.

**INFINFB2569 (Jazzy Select, Select 6, Select 6 Ultra, Select Elite,
Select 14, Select Traveller, Jazzy 614, 614 HD, Z-Chair):**
- **5 years:** main frame, seat post.
- **13 months:** charger, controller, joystick, anti-tip and caster
  forks, metal seat framing, accessories, brakes (electronic function
  only), bearings and bushings, harnesses, plastic (not body), motor/
  gearbox, front rigging brackets.
- Batteries: 6 months from the battery maker. Reconditioned: 6 months.

**INFINFB2608 (J6) and INFINFB2610 (Jazzy 600):**
- **Lifetime:** main frame.
- **2 years:** charger, controller, joystick, caster forks and beam,
  metal seat framing, front riggings and brackets, harnesses.
- **18 months:** motor/gearbox, power seat actuator, **or 13 months
  depending on the HCPCS code**:

| Chair | Code | Terms |
|---|---|---|
| J6 2S-C | K0823 | 2-year |
| J6 2S-SS | K0822 | 2-year |
| J6 2SP-SS | K0835 | 2-year + 18-month |
| Jazzy 600 2S-C / 2S-SS | K0823 / K0822 | 2-year |
| Jazzy 600 3S-C / 3S-SS | K0849 / K0848 | 2-year + 18-month |
| Jazzy 600 3SP-SS / 3SP-C | K0856 / K0857 | 2-year + 18-month |

- **1 year:** accessories, brakes (electronic function only).
- **6 months:** bearings and bushings, plastic (not body); batteries
  (battery maker); reconditioned units.

All: original consumer purchaser only, not third-party payers or
renters under a rental agreement; wear items excluded.
