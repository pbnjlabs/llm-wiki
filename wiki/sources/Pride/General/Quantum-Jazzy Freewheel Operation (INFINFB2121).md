# Quantum/Jazzy Freewheel Operation (INFINFB2121)

7-page product supplement, Rev A, 12 Sep 2007: which way the manual
freewheel levers move on each Jazzy and Quantum series of that era.

| Series | Drive | Freewheel |
|---|---|---|
| Jazzy Select, Select 6, Select 6 Ultra | Pull both levers **up** | Push **down** |
| Jazzy Select Traveller, Go-Chair, Z-Chair | Push **forward** (levers at rear) | Pull **rearward** |
| Jazzy Select 14, 14 XL; Jazzy 1170 XL Plus, 1113 | Turn **inward** | Turn **outward** |
| Quantum/Jazzy 600 series, Quantum 6000/6000Z (Hammer/H2 and Glide motors) | Pull **up** | Push **down** |
| Quantum 1122 series, Jazzy 1113 ATS, Jazzy Select 7 (lever inside each anti-tip wheel) | Push **down** | Pull **up** |
| Quantum 1420 series (one lever at rear, between motors) | Rotate **counterclockwise** | Pull out and rotate **clockwise** |
| Quantum 1121, 1107, Dynamo 1107 | Pull **up** | Push **down** |
| Quantum 610, Quantum/Jazzy 1103 Ultra, Jet 3 Ultra | Push **inward** | Pull **outward** |
| Quantum 1650 (levers at rear) | Push **inward** | Pull **outward** |
| R4000 Hammer/H2 | Pull **up** | Push **down** |
| R4000 Glide | Push **inward** | Pull **outward** |

Note the 1122 / 1113 ATS / Select 7 group runs **opposite** to the
rest: up is freewheel.
