# i-Go Owners Manual (INFMANU5131)

80-page non-medical owner's manual for the folding [[i-Go]] (English,
French, Spanish; Rev C, Aug 2023). Pulled from the PQ-365 owner's manuals / basic operations library on 2026-10-20.

- Easy-remove **lithium-ion battery pack**; main circuit breaker
  (button pops out when tripped; rest a minute, push it in toward the
  rear). Frequent trips: charge more often.
- Charge with the supplied **3-pin XLR lithium charger**: into the
  scooter first, then the wall; two red LEDs = charging, green = full;
  wrong order → unplug both, wait 1 min, redo.
- Tiller: key switch, throttle, light switch, optional USB charger.

Feeds: [[i-Go]], [[Pride-Power-Chair-Care]].
