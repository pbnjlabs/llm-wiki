# Mid-Size Scooter Series Owners Manual (INFMANU4468)

136-page owner's manual (English, French, Spanish; Rev J, Jan 2025)
for Pride's **mid-size scooters**: models **93, 104, 609, 6092, 709,
7092, 610, 6102, 710, 7102, 610DX, 710DX, 710DX2, 610DXW, 710DXW,
710DXW2, 710LX, 710LXW, 710ZT, 710MS, 710PLA, 712, 712DX**. That
covers the Victory 9/10 family ([[Victory]]). A features table lists
console style, frame lock-up style, lights, seat options, suspension
seat post, hi-low switch and handbrake by model. Pulled from the PQ-365 owner's manuals / basic operations library on 2026-10-20.

Beep code table (scooter OMs): 1 battery too low to run; 2 battery
low; 3 voltage too high or charger still connected; 4 current limit
time-out; 5 freewheel lever in freewheel; 6 throttle not centered at
start-up; 7 speed pot error; 8 motor volts error; 9 other internal
error. Turn off and on after fixing ([[S-Drive-Beep-Codes]]).

Basic troubleshooting: dead = key on, charge, **push in the main
breaker**, harnesses connected, power-down timer. Won't move = manual
freewheel lever forward cuts power; pull it back and cycle the key.
