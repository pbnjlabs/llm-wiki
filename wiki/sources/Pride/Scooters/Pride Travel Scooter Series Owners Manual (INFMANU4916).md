# Pride Travel Scooter Series Owners Manual (INFMANU4916)

128-page Pride-branded travel scooter owner's manual (Rev K, Jan 2026),
a separate document number from the universal edition
([[Travel Scooter Series Owners Manual (INFMANU4392)]]) but with the
same features table: models AAP4, 29, 36, 336, 39, 40/44, 40X/44X, 40E/402E/44E/442E/443E/
443EMS, 40LX/44LX, 49, 493, 50LX/54LX, 50LXLIT/54LXLIT, 53/53HD, 54,
54ALX, 54HD, 66/67, 73/74, 83/84 and the Jazzy ZTS. That covers the
[[Elite-Traveller]] (40E/44E), [[Go-Go-LX]] (50LX/54LX),
[[Go-Go-Sport]] (73/74), [[Revo]] (66/67) and [[Ultra-X]]. A features
table lists console, battery pack style, on- or off-unit charging,
frame lock-up and options by model. Pulled from the PQ-365 owner's manuals / basic operations library on 2026-10-20.

Same beep codes and troubleshooting as the universal edition. Use
whichever came with the scooter; nothing found that contradicts the
other.
