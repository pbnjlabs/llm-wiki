# Q6 Edge 3 Stretto Operator Manual (INFMANU5113)

28-page operator manual for the **Q6 Edge 3 Stretto**, US/UK/AU,
Rev C/September 2022.

Covers largely the same structure as the [[J6 Operator Manual|J6 OM]]
(transit tie-downs, comfort adjustments, batteries/charging, care and
maintenance, wheel/battery replacement) with Q6-Edge-3-Stretto-specific
differences:
- References the **TB-Flex Seat** and **TRU-Balance 3 Power Positioning
  System** as separate-manual seating options (see
  [[Tru-Balance-3-Power-Positioning]]).
- Explicitly calls out that joystick-operation info lives in the
  controller's own manual — this chair ships with **Q-Logic 3** (see
  [[Joystick-Controllers]]).
- Transit securement requires either a WTORS 4-point strap tie-down
  (ANSI/RESNA WC/Vol.4 §18/ISO 10542) **or** a docking-type transit
  securement system (§19/ISO 7176-19) — not both interchangeably.
- **Cleaning and Disinfection** section is notably more detailed than the
  J6 OM's (newer revision): named disinfectants for hard/soft surfaces
  (Lysol, Clorox, Bleach-Rite, Citrace, Dispatch, ≤10% diluted bleach) vs.
  a separate lighter procedure for electronics (70% isopropyl alcohol/30%
  water, damp microfiber only, no direct spray).
- Battery compartment uses squeeze-release front cover + rotating rear
  shroud clips (vs. J6's fastener-based shrouds) and quick-release battery
  connectors.
- Corrective-maintenance "when to call your provider" symptom list (motor
  noise, frayed harnesses, uneven tire wear, jerky motion, pulling, chair
  not powering/moving, loose seating) mirrors the
  [[Q6 Edge Basic Troubleshooting|basic troubleshooting sheet]].
