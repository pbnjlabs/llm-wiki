# Lift Chair Hand Control Reference (INFINFB2665 Rev M, 2024)

6-page hand control reference, **Rev M (Sep 2024)**, newer than the
Rev K (2021) on [[Lift Chair Hand Controls (INFINFB2665, INFINFB2695, INFINFB2691)]].
Pulled from the PQ-365 owner's manuals / basic operations library on 2026-10-20.

Changes from Rev K:
- **Flash codes rewritten.** Rev K's "buttons blink every second" (hand
  control or USB device) and "every 5–7 s" (power lost) are gone. Rev
  M: **top two LEDs by the USB port lit** = fault in the hand control
  or the USB device/cable; **no code but the USB port is dead** =
  unplug and replug the device, then call the provider.
- New warning: **don't charge from the USB port during a power
  outage**; it drains the backup battery.
- iPhones: MFi-certified cables only.
- Lock/unlock still **hold about 5 s**; the button lights when locked.
