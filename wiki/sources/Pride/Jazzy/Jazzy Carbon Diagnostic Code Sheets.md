# Jazzy Carbon Diagnostic Code Sheets

Two one-page code sheets from the Jazzy section of the basic operations
library (undated screenshots, uploaded 2026). Pulled from the PQ-365 owner's manuals / basic operations library on 2026-10-20.

**Jazzy Carbon (beep 2 + n):** 2+1 joystick-to-controller cable;
2+2 right motor/plug; 2+3 right brake (lever in place? brake damaged?);
2+4 left motor; 2+5 left brake; 2+6 controller overcurrent, motor
short or overload (brake released? wheels locked?); 2+7 joystick not
centered or poor connection; 2+8 controller fault; 2+9 battery low or
failed (charge; if it persists, replace the battery).

**Jazzy Carbon 27 and Carbon HD (display icons):** controller internal
fault and joystick fault = return to factory service; right/left motor,
right/left **motor Hall**, right/left brake and battery faults = check
the connector and wiring, then troubleshoot that part.

The owner's manual calls 2+8 "joystick failure"; the sheet says
controller. Check both.
