# Jazzy 614 / 614 HD Basic Troubleshooting Instructions (INFINFB2468)

3-page end-user/provider supplement for the **Jazzy 614 and Jazzy 614
HD with Dynamic controller**, Rev A, May 2010. The same symptom
checklist as [[Q6 Edge Basic Troubleshooting]] (dead system, short
range, slow, pulling, clicking), plus a **Dynamic flash code table**:

| Code | Meaning | Do |
|---|---|---|
| 1 | Possible stall timeout | Joystick off, then on |
| 2 | Battery fault | Charge; check battery connections and fuses |
| 3 / 4 | Left / right motor fault | Motor plugged in? |
| 5 / 6 | Left / right park brake fault | Brake not in freewheel? |
| 7 | Joystick fault | Joystick connection |
| 8 | Power module fault | Power module and battery connections |
| 9 | Controller communication fault | Bus connections joystick to power module |
| 10 | Controller fault | Technical Service |
| 11 | Incompatible device fault | Technical Service |

Also: battery LEDs chasing right to left = **lockout, press the horn
twice**; chasing left to right alternating with steady (speed gauge
flashes on joystick movement) = **charger plugged in**, or the 4-pin plug
isn't in the power module (charger inhibit); battery LEDs flashing
rapidly nonstop = joystick out of neutral at power-up.

Code 10 is "controller fault" here and "unknown fault" in the
[[Jazzy 614 Technical Troubleshooting Guide (INFMANU3834)]]; the action
is the same (call Pride).
