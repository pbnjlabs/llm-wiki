# Q6 Edge 3 Specifications (INFINFB3925)

2-page Quantum spec sheet for the **standard Q6 Edge 3** (not the
Stretto), US/UK/AU, INFINFB3925/Rev D/October 2022. The raw filename
carries a browser "(2)" suffix.

Headline: Class B (Group 3), 300 lb, up to **6.25 mph**, **4.5 mph with
iLevel** (UK: 4 mph, 3.2 mph with iLevel), range up to 19.7 mi, SRS
suspension, two NF-22 batteries, 8 A off-board charger, max slope 7.5°
(US) / 6°, climbs 3.5 in. Full figures on the model page.

This is the first document on file for the standard Edge 3, the chair in
PMS's [[2026-09-25 Q6-Edge-3 iLevel no power]] field note.
