# Q6 Edge Technical Troubleshooting Guide (INFMANU4109, Rev A 2011)

25-page first edition of the Q6 Edge **NE / NE+ / Q-Logic** Technical
Troubleshooting Guide, Rev A, February 2011. **Superseded** by
[[Q6 Edge Technical Troubleshooting Guide (INFMANU4109 Rev B, 2012)]];
use Rev B.

Same sections and test values as Rev B (no power, System Lock, charger
or drive inhibit, open motor, motor/brake, module, joystick and
communication errors, low battery, NE / NE+ / Q-Logic tables), written as
numbered steps keyed to numbered 3D and 2D wiring diagrams (connectors
1a, 2b…). Rev A's Q-Logic table also lists **#1–#6 software fault**
(power-cycle, check module connections, update module software), which
Rev B drops. The numbered connector diagrams are handy if Rev B's
flowcharts are hard to follow.
