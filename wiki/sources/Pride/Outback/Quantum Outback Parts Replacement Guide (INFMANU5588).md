# Quantum Outback Parts Replacement Guide (INFMANU5588)

40-page Quantum PRG, Rev A, November 2025, for the **Outback**
four-motor outdoor chair. The first Outback document on file besides
the 2025 lineup chart.

Sections: chair prep, seat removal (TRU-Balance 3 REAC lift or TB
Flex), rear motor liner, rear carrier shroud, drive wheel and tire,
front and rear fenders, **front light pods**, side shroud body mount,
suspension, **motors and motor harness routing (left and right)**,
**terminal block** (and its left/right wiring), **propping the seat
back**, batteries, breaker and battery harnesses, front and rear
**sway bars and bushings**, front frame, front motor mount, **front tie
rod**, rear control arms, power module, light harness and module,
AM3/AM3L, PTO backup camera, seat interface.

| Fastener | Torque |
|---|---|
| Seat to interface (REAC lift, TB Flex) | 35–44 N·m |
| Lug nuts | 25.8–28.5 N·m (19–21 ft·lb) |
| Split-rim screws | 4–5 N·m, Loctite 242 |
| Light pod nuts | 3–4 N·m, **hand tools only** |
| Suspension nut and bolt assemblies | 15–22 N·m |
| Motor to motor mount nuts | printed "19–22 N·m (11.8–16.2 ft·lb)": the conversions don't match (16–22 N·m = 11.8–16.2 ft·lb); confirm |
| Battery fuse screw | 3.7–4.1 N·m |
| Sway bar / articulating limiter screws | 10–15 N·m |
| Front frame / motor mount assembly | 80–88 N·m (59–64.9 ft·lb) |
| Tie rod nuts | 30–35 N·m |
| Control arm and motor mount bolts | 18–22 N·m |
| Light module / last section bolts | 30–36 N·m |

**Terminal block:** the right motors connect to the **middle**
section, the left motors to the **bottom** section; note the ring
terminal orientation before taking it apart; it must be reassembled
exactly. Motor and light harnesses must be routed as found.
