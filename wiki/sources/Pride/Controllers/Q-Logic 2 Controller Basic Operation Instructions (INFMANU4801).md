# Q-Logic 2 Controller Basic Operation Instructions (INFMANU4801)

32-page end-user manual for the **Q-Logic 2** controller (Rev B, Feb
2020). Pulled from the PQ-365 owner's manuals / basic operations library on 2026-10-20.

On/off–mode select lever, battery meter, sleep mode, lock, attendant
control and the **legacy Q-Logic error numbers**: 35/37 joystick
fault/connection, 36/110 not centered, 46 high battery, 105 low
battery, 53 and 75 motor not connected/disconnected, 90 motor/brake,
132/201 motor fault, 195 motor disconnected/shorted. Use the legacy
table, not the Q-Logic 3 one.
