# Q-Logic 3 — Basic Operation Instructions (INFMANU4809)

28-page end-user manual for the **Q-Logic 3** hand control (touchscreen
generation — successor to Q-Logic). End-user-level operation, as opposed
to the provider-level [[Q-Logic 3 Programming Guide]].

Covers the touchscreen hand control's Home screen, Settings menu, drive
profile selection, actuator (seat) screen, Standby Select (navigate
profiles without a dedicated Mode key), and the same category of error
codes/warnings as the legacy Q-Logic (info/warning/error/general-error
severity levels), plus care/maintenance and warranty pointers back to the
power chair's own manual.

Feeds into: [[Joystick-Controllers]].
