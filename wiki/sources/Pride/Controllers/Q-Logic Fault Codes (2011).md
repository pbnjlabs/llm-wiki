# Q-Logic Fault Codes (2011)

10-page spreadsheet printout ("Updated error codes 17MAR11.xls", March
2011) of the **legacy Q-Logic** fault codes, 1–245: fault code, error
text, possible cause, suggested remedy. No Pride document number.

It's the troubleshooting table from the 2008
[[Q-Logic Technical Manual (INFMANU3580)]], extended with later codes
(178–245: encoders, seat re-home, mode switch and D-Sub-9 supervision,
MIO overflow, firmware uploaded, motor stall, power reduction, duplicate
device number, all profiles disabled, incompatible start manager) and a
few wording changes (e.g. #237 is "Incompatible Startmanager" here,
"Start Manager Update" in 2008).

These numbers are **not** the Q-Logic 3 numbers. See
[[Q-Logic 3 Fault List (2025)]].
