# Q-Logic 3 Fault List (2025)

13-page spreadsheet printout (PDF made February 2025) of the
**Q-Logic 3** fault codes, about 1–221: code, description, explanation
and action steps. No Pride document number.

Much fuller than the 12 codes in the
[[Q-Logic 3 Basic Operation Instructions]]: jack-switch disconnects
(5–13), D-Sub and proportional input (13–14), encoders (15, 19, 40),
brake shorted or wrongly programmed (16–17), main contactor (28–30),
motor stall (31), firmware mismatch (42), DMS (49), device
exchanged/added/removed (50–52), Sip N Puff (53–54, 63–64), actuators
(56–58, 66–69), traction control (72, 84–85), not charging (75),
**TRU-Balance 4 actuator and switch faults (150–177)**, and system
errors needing a reboot (202–215), firmware hardware check (220) and the
**gyro/accelerometer (IMU)** fault (221).

Several TRU-Balance 4 codes say "refer to the **Tru-Balance 4 technical
troubleshooting guide**", which isn't on file.
