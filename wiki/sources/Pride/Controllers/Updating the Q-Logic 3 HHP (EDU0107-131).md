# Updating the Q-Logic 3 HHP (EDU0107-131)

8-page Quantum education handout, REF EDU/0107-131 Rev 0 (undated), on
updating and **registering** a Q-Logic 3 hand-held programmer.

1. Save the two firmware files Quantum emails you to the desktop.
2. Plug the HHP into the PC; it shows as a removable disk. Drag both
   files onto it.
3. Unplug and replug: the update starts by itself. Unplug when done.
4. Plug the HHP into a Q-Logic 3 chair: a registration screen appears;
   "Register" shows a **12-digit key code**.
5. On the Quantum **Cloud** server: Device Management > Registration of
   HHP(1313) > Add, enter the key, Register. The Cloud returns a code.
6. Type that code (with the dashes) into the HHP's on-screen keyboard.
   **Move the cursor to "Space" before pressing OK**, or the letter under
   the cursor gets added and you have to start over.
7. Set the programmer to **Dealer**.

A Q-Logic 3 chair is required for registration.
