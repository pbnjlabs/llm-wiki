# GyroSet Vigo Setup for Q-Logic 3 (INFINFB4305)

3-page Quantum install sheet, INFINFB4305/Rev A/November 2020, for
programming Q-Logic 3 to take input from the **GyroSet Vigo**, a
head-worn gyroscopic drive control made by **Now Technologies**
(nowtech.hu). Quantum employees and authorized providers only; not an
endorsement, and not for troubleshooting the Vigo itself.

Hookup: Vigo → Bluetooth → **Cubo** → micro-USB → **GyroSet Link** →
9-pin **D-sub** on the **Enhanced Display or SCIM**.

Programming (HHP): Program Adjustments > Enhanced Display > Input
Configuration > **Proportional**; then Proportional Input > Proportional
Calibration, and with the Vigo on the client's head have them **move
their head slowly in two circles**, then OK. Econ-W: connect with the
USB-to-XLR CANbus cable, same two settings; the chair shows Output
Inhibited during calibration and returns to System Ready.
