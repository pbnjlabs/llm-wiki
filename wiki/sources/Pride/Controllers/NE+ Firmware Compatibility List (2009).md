# NE+ Firmware Compatibility List (2009)

1-page chart (filename dated 12-30-09) for the **NE+** electronics, the
Q-Logic-branded system on Pride's **Power Base 75** (1750-2009). Rows
are compatible version sets keyed by the power base version: 1.06,
1.09, 1.10, 1.11.

Modules: hand control J (1751-6009), hand control AJ (1751-6209), hand
control LJ (1751-6309), attendant control (1752-2109), light module
(1755-0109), AM1 (1755-1009), AM2 (1755-2009), light actuator module
LAM2 (1755-2109), handheld programmer (1311-3309, 2.25/2.26) and PC
programming station (1314-3302, 4.0.1 builds 462–529, "NE, NE+ & Vista"
compatible).

This is the only NE/NE+ document on file. There's still no NE or NE+
operation manual.
