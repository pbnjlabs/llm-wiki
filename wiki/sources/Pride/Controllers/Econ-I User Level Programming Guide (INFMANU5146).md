# Econ-I User Level Programming Guide (INFMANU5146)

24-page guide to **Econ-I**, the iOS app for programming Q-Logic 3 over
Bluetooth at **user level** (no log-in), INFMANU5146/Rev A/September
2020.

- **Connecting, Q-Logic 3:** Aux screen (mode command, or Home button +
  two left inputs) > highlight "Econ/Interactive Assist" > right input
  to tick it > note the chair ID at the top. In the app: Continue
  without Log-in > Bluetooth icon > chair ID > Pair (forward input on
  the chair if the codes match; only the first time) > "Loading Device
  Data" > forward input to accept access.
- **Connecting, Q-Logic 3e:** Settings screen > right input to the
  Bluetooth screen > forward input turns Bluetooth on; the ID is at the
  bottom.
- **App functions:** parameter menus with help text, **XPA** config
  files (create, open, copy, email, rename, delete), photo album for the
  chair's display, **System** (each module's part number, build date,
  serial, hardware and software versions) and **Battery Statistics**
  (charging history).
