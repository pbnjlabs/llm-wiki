# Q-Logic Seat Configuration Settings (AAM)

2-page chart of the **Advanced Actuator Module (AAM) configuration
numbers 1–47**: which actuator channels (A1 tilt, A2 recline, A3
elevate/lift, A4 left leg/both legs/foot platform, A5 right leg/back)
each number turns on. 1–39 are the seat configurations (legs, elevate,
recline, tilt and their combinations, with synchronized recline + legs
or foot platform); **40–47 are lift & tilt** configurations. Undated.

The 2008 [[Q-Logic Technical Manual (INFMANU3580)]] lists only 1–39, so
this chart is newer.
