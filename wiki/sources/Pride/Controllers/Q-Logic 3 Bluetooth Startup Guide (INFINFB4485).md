# Q-Logic 3 Bluetooth Startup Guide (INFINFB4485)

16-page guide to letting a Q-Logic 3 or 3e chair **control a phone,
tablet or computer** over Bluetooth, INFINFB4485/Rev A/May 2022. An
expanded edition of the 2018 two-page
[[Q-Logic 3 Bluetooth Startup Guide (EDU0112-12, 2018)]].

- **Apple (Switch Control):** a provider must first enable Assistive
  Switch Control and Home Screen access with a programmer. Then on the
  chair: Home > left commands > Bluetooth Operation > tick Assistive
  Switch Control. Pair "SwitchControlXXXX" in iOS Bluetooth, confirm
  with a forward command, then set up each joystick direction as an
  external switch (4 directions plus 4 "long" commands = 8).
- **Android/Windows (mouse emulation):** enable Mouse under Bluetooth
  Operation; Home > right > Mouse Connections > New shows the ID; pair
  "MouseXXXX", confirm with a forward command.
- **iOS 15.4.1+ AssistiveTouch:** pair the chair as a mouse instead of a
  switch. Dwell on the chair works without iOS dwell; to use iOS's own
  dwell, set the chair's Mouse Clicks to **Switches**. Key I / Key II
  on the **QL3 EX** hand control can be set to Custom MIO, mapped to
  left/right mouse click in Econ-W, then assigned iOS actions.
- Tips: gray icons = unpaired, blue = paired; leave the mouse screen
  with the on/off lever up, Key I, Home or Key II.
