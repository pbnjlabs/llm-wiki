# Econ-W User Level Programming Guide (INFMANU5125)

16-page guide to **Econ-W**, the Windows programming app (from
quantumrehab.com), at **user level**, INFMANU5125/Rev A/May 2020.

- **Connecting:** same Aux > "Econ/Interactive Assist" tick as Econ-I;
  the chair shows as **"Chair-<ID>"** on Windows. Open Econ-W, "continue
  without login" (log-in is for dealer level and above), Bluetooth icon,
  pick the chair, confirm pairing on both, **forward input** on the chair
  to accept.
- **Menus:** Account (revalidate access, user details), Help (web
  update, about), File (open/save **.xpa** files), Settings (language,
  XPA language, online updates, delete cache, **set the chair's clock**,
  access level). Connect by **cable (dealer only) or Bluetooth**.
- **Tools:** parameter list with help text, Photo Album Manager,
  **Infrared Remote Control** project editor (menus, list/function/remote
  templates, channel build), **Device List** (each module's part
  number, build date, serial, hardware and software versions) and Open
  Cloud Web Page (dealer only).
