# Q-Logic 3 Programming Guide (Rev A, 2019)

38-page US/Canada Q-Logic 3 provider programming guide,
INFMANU5071/**Rev A/July 2019**. **Superseded** by the Rev B/September
2020 edition already on file, [[Q-Logic 3 Programming Guide]] (44
pages). Same document number and section order (Setup, Hand Control,
Head Array, Sip-N-Puff, Switches, Multiple Input Devices, Seat,
iAccess, Bluetooth, Infrared, Reminders, HHP).

Rev B adds material, mainly in Setup and Hand Control (startup input
device and entry-point options, Clinic Mode, provider info, key/button
options, Custom MIO, double-command and jack settings, the proportional
alternative drive controls such as mo-Vis). **Use Rev B.** This file is
kept only as the older revision.

Feeds into: [[Joystick-Controllers]] (via Rev B).
