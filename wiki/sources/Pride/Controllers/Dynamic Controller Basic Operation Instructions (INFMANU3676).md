# Dynamic Controller Basic Operation Instructions (INFMANU3676)

16-page Pride BOI for the **Dynamic** controller (Dynamic Controls), **50 A or 60 A**, INFMANU3676/Rev F/June 2022. Pride's charts call the 50/60 A Dynamic "Dynamic LiNX" (Jazzy EVO 614/614HD, Elite 14, 600 ES, Elite HD).

Covers: 4-, 7-, 8- and 9-key keypads (lights, hazard and turn keys on the bigger ones), 8-LED battery meter, **16-LED speed indicator**, **service indicator** that flashes the error code, attendant control indicator, actuators via the actuator select key, **lock: hold on/off 4 s; unlock: press the horn twice within about 10 s** of power-on, sleep (any key wakes it), **OONAPU** (speed lights flash while the joystick is off center), the **11 error codes**. Off-board charger: 8 A max, Neutrik NC3MX only.

Quirk: the features list describes OONAPU with the thermal-rollback text by mistake. The error table and lock procedure match Golden's **Shark** table ([[Shark-Diagnostics]]), not Golden's 7-code LiNX table ([[LiNX-Diagnostics]]).
