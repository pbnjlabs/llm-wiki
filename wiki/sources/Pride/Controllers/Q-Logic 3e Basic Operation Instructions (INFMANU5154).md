# Q-Logic 3e Basic Operation Instructions (INFMANU5154)

44-page end-user manual for the **Q-Logic 3e** (Rev D, Mar 2026), the
controller on the J4E/J4E HD. Fills the Q-Logic 3e BOI gap. Pulled from the PQ-365 owner's manuals / basic operations library on 2026-10-20.

- Keys: on/off, horn, **Mode**, **Page**, soft keys (speed arc up/down).
  Drive, seat (actuators, iLevel elevation, TB4 anterior tilt, AFP
  articulate), memory seat and settings screens.
- **Lock: hold the Mode button until it turns off** (lock-out is off
  from the factory). Unlock: on, full forward to a beep, full reverse
  to a beep.
- **USB-C port up to 1.5 A.** Bluetooth programming must be accepted
  with a forward command; Interactive Assist works the same way.
- Battery meter: **green ~100–50%, yellow 49–25%, red 24–0%**; pop-ups
  at **50, 30 and 15%** (can be turned off in Econ-W/Econ-I).
- Thermal rollback to 20%. Attendant control: mode button cycles drive
  profiles and seat mode.
- Error table: same codes as the 2026 Q-Logic 3 BOI.
