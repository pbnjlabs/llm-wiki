# Dynamic LiNX Fault Code Sheet

One-page fault code table for **Dynamic LiNX** electronics, from the
Jazzy section of the basic operations library (undated, uploaded 2026).
Pulled from the PQ-365 owner's manuals / basic operations library on 2026-10-20.

| Code | Cause | Fix |
|---|---|---|
| 1 | Remote/joystick | Check cables; replace remote |
| 2 | Network or configuration | Cables, Bluetooth pairing, reconfigure, charge, check charger, replace modules |
| 3 / 4 | Left / right motor | Motor, connections, cables |
| 5 / 6 | Left / right park brake | Brake, connections, cables |
| 7 | Module error (not the remote) | Modules; replace the **LiNX Access Key** or power module; charge; if stalled reverse away; if pushed while off, power-cycle |

**Copy error on the sheet:** codes 4 and 6 (right side) say "check the
**left** motor/brake". Check the right side.
