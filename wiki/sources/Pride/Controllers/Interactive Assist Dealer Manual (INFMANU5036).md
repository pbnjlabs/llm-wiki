# Interactive Assist Dealer Manual (INFMANU5036)

48-page "for dealer use only" manual for **Interactive Assist**,
Quantum's remote-programming link for Q-Logic 3, INFMANU5036/Rev
A/October 2018. Three parts: Remote **Econ-W**, the **Android** app
(Android 5.0+, Google Play) and the **Apple** app (iOS 9+, App Store).
The app is published by Curtis Instruments.

How it works: the user's phone pairs to the chair by Bluetooth and
relays it over the internet; the app shows a **channel and passcode**
that the user gives the provider, who enters them in Econ-W. The chair
asks the user to accept with a **forward input**. Each session times
out after **1 hour**.

- **Dealer-to-user access:** provider can view parameters, seat
  configurator and Mapped IO; can change only **user-level** parameters
  (switch Econ-W's access level to "user" first), plus photo album and
  IR configurator.
- **Provider-to-provider access:** a provider on site with the chair
  logs in to the app (not the same log-in as the remote Econ-W) so the
  remote provider gets dealer write access.
- Remote Econ-W also shows the device list, **error list**, real-time
  monitor values (under 500 ms delay), **battery statistics**, a live
  copy of the chair's screen, the access/change log and a chat window.

The acknowledgment the app requires: give the channel/passcode only to
a trusted provider; only qualified technicians use it; use it to read
settings and troubleshoot or change **non-performance** settings; it
**doesn't replace a face-to-face evaluation and programming**.
