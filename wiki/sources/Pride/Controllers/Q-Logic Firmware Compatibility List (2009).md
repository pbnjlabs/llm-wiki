# Q-Logic Firmware Compatibility List (2009)

3-page Q-Logic chart dated 12-30-09 (filename). Each row is a set of
module firmware versions that work together ("all software versions in
one row are compatible"), keyed by the **Powerbase 100** (1750-3509)
version: 1.17, 1.26, 1.49, 2.19, 2.26, 2.42, 2.43, 2.45.

Columns: hand control (1751-0009), hand control with lights
(1751-0109), stand-alone joystick (1752-1109), attendant (1752-2109),
Enhanced Display (1753-2109), AAM (1754-6009), environmental control
unit (1756-0009), Sip & Puff (1757-0009), AM1 (1755-1009), AM2
(1755-2009), light actuator module LM2 (1755-2109), light module
(1755-0109), handheld programmer (1311-3309) and PC programming station
(1314-3302, builds 4.0.14 to 4.0.1 build 529).

Key point: on powerbase firmware **1.17, 1.26 and 1.49 the AM1, AM2,
LM2 and light modules are "N/A with this power base firmware"**. They
need powerbase **2.19 or later**.
