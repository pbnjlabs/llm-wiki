# Q-Logic Error Code Reference Guide (INFINFB2653)

13-page booklet, Rev A, February 2011: the **legacy Q-Logic** error
codes (1–245), the same set as [[Q-Logic Fault Codes (2011)]] in a
diagnosis/solution table, plus the four message types (information,
warning, error, general error; the last can shut the chair down).

When calling Quantum about a general error, have the **module,
software version, error number and line number** ready.

No new codes; full list on [[Q-Logic-Fault-Codes]]. Its #35 is
"joystick center fault", matching the 2011 list.

Feeds into: [[Q-Logic-Fault-Codes]], [[Joystick-Controllers]].
