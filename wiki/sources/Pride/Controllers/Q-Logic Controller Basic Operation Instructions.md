# Q-Logic Controller — Basic Operation Instructions (INFMANU3347)

32-page end-user manual for the original **Q-Logic** controller (legacy
generation — predecessor to Q-Logic 3), Rev D/January 2011.

Covers hand control, "Q-Logic with Lights" hand control (adds horn/turn
signal/hazard/headlight buttons for road use), Attendant Control,
Stand-alone Joystick, and Enhanced Display (color LCD, optional IR, can
drive specialty input devices).

Key mechanics: On/Off and Mode Select Lever (push up to power on/cycle
through up to 5 drive profiles, push down to power off — **not** for
emergency stop), joystick drive, programmable lock/unlock (hold lever until
off = lock; full-forward-then-full-reverse joystick = unlock), speed
adjustment knob, keypad (Horn/Key1/Key2/Menu), LCD drive screen (180° SOC
arc, speed, profile, trip/odometer), actuator adjustment via seat screen (5
power seat actuators), Main Menu (clock format, backlight, units,
language, trip/odometer reset), Sleep Mode (0–240 min timeout), Thermal
Rollback (reduces output to 20% when hot), Battery Condition Meter
(green/amber/red).

Includes the full **Q-Logic error code table** — see
[[Joystick-Controllers]] for the reproduced table (joystick
fault/not-centered, high/low battery voltage, motor not
connected/disconnected/fault, charger drive inhibit, center detect fault,
drive/actuator restriction, motor disconnected/shorted).
