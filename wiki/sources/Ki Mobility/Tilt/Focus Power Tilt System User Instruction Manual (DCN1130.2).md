# Focus Power Tilt System User Instruction Manual (DCN1130.2)

Ki Mobility user instruction manual and warranty for the **Focus CR power tilt** (DCN1130.2, 22 pages, English then Spanish). The wiki read the English half.

## Covers

- **Capacity** (user plus everything carried): Standard and transit **300 lb (136 kg)**.
- **Transit:** Transit option.
- Kit that adds **powered tilt** to a manual Focus for repositioning and pressure relief.
- Parts: battery, interface control box, power tilt rack assembly, pendant controller, motor, battery tray charging port and cable, power tilt switch.
- Uses a **REAC RCB10** 4-channel control box with a **2 Ah battery pack** and an external charger (EN 12184 / EN 12182). Ports: 1 single direction (dual switch), 2 opposite direction, 3 toggles direction (single switch), 4 alternate; switch interface cables for adaptive switches.
- Install and motor replacement are in the [[Focus Technical Manual (DCN0340.12)]].
- **Warranty:** as the Focus CR (frame, hangers, tilt assembly and quick-release axles for the original purchaser's life).
