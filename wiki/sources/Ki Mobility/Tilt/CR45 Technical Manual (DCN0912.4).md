# CR45 Technical Manual (DCN0912.4)

Ki Mobility **dealer technical manual** for the CR45 (80 pages), written for a qualified technician at an authorized Ki dealer (an ATP or trained clinician). It supplements the user manual. Procedures are mostly step photos; the wiki summarizes what's covered and the values in the text.

## Covers

- Seat height configuration charts, frame setup by depth, axle and fork references, quick-release axle, frame depth and CG references, base frame and roller plate references, caster construction and **caster seat height matrix**, chair width, **hand tilt and foot tilt mechanism installation**, transit, anti-tips, back height and angle, **growing seat pan**, solid seat pan, **adjusting the COG**, wheel locks, attendant foot lock, T-arm, side guard, handrims, footrest length, 4-way latch, **bearing construction**, armrest, IV holder, pediatric Pro ELR, ELR, canopy, ergo grip.
- Frame: base frame 1-1/4 in square, seat frame 1 in.
- No torque values in the text layer; they are in the figures.
- Spoke tension: one-arm-drive, Maxx and low-cost spokes 60–100 kgf; drum-brake wheels 90–120 kgf radial side, 60–90 kgf crossed side; Superlight 92–112 kgf.
