# Transit Retrofit Kit Pre-Installation Inspection (104975 Rev D)

One-page Sunrise Medical checklist (104975 Rev. D, © 2025) that **must
be done before installing a Transit Retrofit Kit** on an existing chair.
Fix anything found first; if it can't be fixed, **don't install the
kit**.

## Covers

1. **Frame welds:** no visible cracks; clean dirt out of weld and bend
   areas to inspect them.
2. **Hardware:** no bent, cracked or loose parts; tighten to the owner's
   manual torques; replace anything broken, bent or corroded.
3. **Wheels, casters, forks and axles:** no dents, plastic cracks or
   bends.
4. **Tubing and mounting holes:** no dents, bends or deformation that
   would affect the mounting surface; mounting holes must show **no**
   deformation.

The kit's own install instructions aren't on file.
