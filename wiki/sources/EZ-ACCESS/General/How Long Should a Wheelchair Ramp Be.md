# How Long Should a Wheelchair Ramp Be?

EZ-ACCESS blog article (2026-09-03), clipped from the web — not a
manual. Consumer-facing planning guide for sizing a ramp from vertical
rise.

## Covers

- The 1:12 rule of thumb: ~1 ft of ramp per 1 in of rise; worked
  examples (12/24/36 in rise → 12/24/36 ft).
- Rise vs. run definitions; 4-step calculation (measure rise → ×12 →
  ÷12 to feet → check available space).
- **Rise-to-length table** (1:12): 6 in → 6 ft, 11-3/4 in → 12 ft,
  18 in → 18 ft, 23-1/2 in → 24 ft, 30 in → 30 ft, 35-1/4 in → 36 ft.
  Note the odd values — see [[Ramp-Slope-and-Length]].
- Ramp length by step count (2/3/4/5 steps at ~7 in each → ~14/21/28/35
  ft), with the warning to always measure total rise, never count steps.
- What to do when there isn't room for a straight run (turns, platforms,
  modular layout — never "shorter and steeper").
- Common design mistakes: too short, rise not fully measured, ignoring
  landings and door clearance, not planning for daily use.
- Ramp type by use: modular (long runs), portable (short/temporary),
  threshold (small height changes).
- ADA as benchmark only for homes; check the mobility device owner's
  guide for acceptable slope and chair direction.
