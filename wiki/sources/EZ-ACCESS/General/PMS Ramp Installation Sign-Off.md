# PMS Ramp Installation Sign-Off

PMS's **installation sign-off** for modular ramps. One page, blank,
undated. Filed with the other PMS ramp forms under EZ-ACCESS/General.
PMS's phone and fax numbers are left out.

## Section 1: jobsite and end user

Appointment date, project name, end user, phone, property address
(customer details; never copied into the wiki).

## Section 2: site check-off

- Ramp installed **per the layout drawing**
- **Level and slope haven't shifted** during installation
- **All fasteners secure** and in place
- **Remove debris and metal chips** from the ramp surface; clean up the
  job site
- **Walk on the assembled system**, checking for undue movement
- Tell the end user the install is complete and answer questions

## Section 3: installation check-off

- **Ratio:** all platforms at the right height so **no ramp run is
  steeper than 1:12**, "unless specified on layout". PMS's house
  standard is 1:12 on every run ([[Ramp-Slope-and-Length]]), so this
  exception doesn't apply (confirmed by the human).
- **Platforms:** level **within 1:50**, with **water runoff directed
  away from the building**.
- **Brace assembly kits** on all **support tubes over 36 in** (platforms
  and ramp sections). **Platforms need one set of braces on each of the
  four sides.**
- **Inside corner kits** on all turn/turnback platforms.
- **Closure kits** on all openings **10 in wide or larger**.
- **Loops** on all ascending/descending ramp runs, unless a corner or
  closure kit is installed there.
- **Pictures:** top and bottom of the ramp, the **entire ramp (loops
  visible)**, and close-ups of corner kits, closure kits, threshold
  ramps, bridge plates, brace assemblies, lightning rods, tie-down kits
  and any modifications to the residence.
- **Mobility equipment test:** the end user tries the ramp with their
  own mobility equipment and finds no problems (turn radius, transfer
  angles, etc.).

## Section 4: approval (renter/owner)

- **End user:** satisfied with the location, installation and
  structural integrity; instructed on proper use, safety and
  maintenance; received warranty and safety/maintenance information.
  **If they notice damage or a problem, they stop using the ramp and
  contact the installer.**
- **Property owner / landlord / manager** (if different): confirms they
  allowed the ramp to be installed.
- End user name, relationship, signature and date; owner name,
  relationship, signature and date.
