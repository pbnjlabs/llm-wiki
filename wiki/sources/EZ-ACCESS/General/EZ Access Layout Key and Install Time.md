# EZ Access Layout Key and Install Time

One-page Visio sheet (revision date 7/10/19). **The author and origin
are unknown.** It uses the same drawing style as
[[EZ Access Parts and Pieces]], which is not a PMS document, so don't
assume these times are PMS's own standard. It serves two purposes:

1. **Layout key**: the drawing symbols used on ramp layout drawings for
   each component (closure/corner kits, threshold ramps, bridge plates,
   SUITCASE ramps, the green dot for ramp bracing and the red dot for
   platform bracing, gate post, MRST/MRLT, platforms, ramp sections,
   landing pad, stairs).
2. **Install time per component**, for estimating labor. Tabulated on
   [[Ramp-Install-Time-Estimates]].

"Modifications" are marked **Prior Authorization** rather than timed.

It does **not** explain the odd rise-to-length values in the EZ-ACCESS
blog tables (see [[Ramp-Slope-and-Length]]); that lead is closed.
