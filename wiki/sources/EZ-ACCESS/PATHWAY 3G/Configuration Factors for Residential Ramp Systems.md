# Configuration Factors for Residential Ramp Systems

EZ-ACCESS blog article (2021-12-01), clipped from the web. An
11-factor checklist for evaluating a home for a residential **modular**
ramp system (i.e. [[PATHWAY-3G]]-class products).

## Covers

1. Appearance — aluminum doesn't deteriorate like wood; landscape around
   it; use existing grade to shorten the ramp.
2. Slope — no steeper than 1:12; 1:15, 1:18, 1:20 are easier for users
   with limited stamina.
3. Shape — straight, L, U, switchback; driven by grade, space, length.
4. Design — reach the exact rise: attach to the porch or add a top
   platform for a flush transition; consider side stairs for others.
5. Landings — top, bottom, and mid-run where needed.
6. Length/width — **ideally no more than 30 ft between landings**; width
   set by the mobility device.
7. Space — map full length/width/height/shape footprint.
8. Weight capacity — must cover user + device + helper.
9. Features — handrails, pickets on handrails.
10. Location — headroom (awnings, protruding objects), AC units/window
    boxes in the way, route to driveway/parking.
11. Traction — slip resistance for climbing and braking when wet.
