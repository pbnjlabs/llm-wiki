# PATHWAY 3G Ramp Requirements Worksheet (EZ-ACCESS 4051_D)

EZ-ACCESS's 2-page **Environmental Survey / Ramp Requirements
Worksheet** for a PATHWAY 3G quote and layout (form **4051_D**; the PDF
is titled "Quote & Layout Request Form", created 2022-04-08). It's
EZ-ACCESS's form, not PMS's: **PMS uses its own
[[PMS Ramp Site Evaluation Form]] and the [[Ramps Handbook]] method**,
which rank above it. Useful as a cross-check or when sending a layout
request to EZ-ACCESS.

## Covers

- **Entry measurements A–J:** step width (or between rails), step depth,
  step rise, porch width, porch rise, porch depth, door usable width,
  exterior threshold rise, interior threshold rise (each with a
  "threshold ramp needed" box), threshold depth. Anything that doesn't
  apply is entered as 0.
- **Total rise = exterior threshold (H) + step or porch rise (C or E) ±
  grade variation.** Add a decline, subtract an incline.
- Door swing (in/out, left/right), bridge plate needed, ramp and
  platform surface (solid or expanded metal), handrail style (two-line,
  vertical or horizontal pickets).
- Page 2: bird's-eye sketch on a 1 ft grid, showing obstacles
  (driveway, walks, trees), the door swing and the top landing's area.
