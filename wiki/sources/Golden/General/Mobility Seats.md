# Mobility Seats (Photo Catalog)

4-page illustrated seat-code catalog (photos + dimensions + confirmed
model list per code), complementing the [[Mobility Seating Matrix]]
table. Names several models with no manuals on file in this wiki yet:
**GR575 (Patriot)**, **GP205, GP207, GP208** — flagged as future ingest
candidates if their manuals turn up. Confirms GP605/GP620 share SM9/SMV
high-back and van/pan codes, with GP620 exclusively getting the largest
24"x20" size in each family.
