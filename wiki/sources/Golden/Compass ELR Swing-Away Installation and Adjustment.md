# Compass ELR/Swing-Away Installation and Adjustment

1-page general Compass procedure (not tied to one GP6xx number): describes
the standard Compass "H-frame" bracket/hanger system that both ELRs and
Swing-aways mount to via the same hanger pins. Explicitly notes the CTOR
system and optional power seat use a modified frame style but the *same*
brackets/hangers, attaching the same way — i.e. this hardware family
spans the plain, CTOR, and power-seat Compass frame variants. Height
adjustment bolt position differs by attachment type (ELRs: front of tube;
Swing-aways: rear of tube).
