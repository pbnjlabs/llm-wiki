# Companion Service Guide (GC240, GC340, GC440)

29-page field service guide for the Companion, R-Series (Dynamics)
controller, 18-24VDC system, two 35AH U1 batteries.

Contents:
- Component-by-component reference (location, function, connections,
  failure signs, test procedure, expected reading, serviceable action) for
  every electrical part: circuit breaker (50A), batteries, battery/power
  harnesses, controller, main harness, motor harness, motor/brake
  assembly, charger harness, throttle pot, speed pot, key switch, headlight
  LEDs, taillights, off-board charger
- Scenario 1: key on, no power — step-by-step voltage-check tree from
  batteries → controller → main harness → key switch
- Scenario 2: batteries won't charge — voltage-check tree from charger
  port → controller → main harness → charger harness fuse
- Flash Codes #1-9 (batteries low/very low, high battery voltage, current
  limit timeout, brake fault, paddle/throttle faults, motor voltage fault,
  controller fault) — see [[Flash-Beep-Diagnostics]], same numbering as the
  VA Operator Manual's "Flash/Beep Codes"
- Replacement instructions: motor/brake assembly, motor brush, drivewheel,
  battery, throttle pot, key switch, control panel fuse, circuit breaker,
  controller, charger harness fuse, main harness (340)
- Appendices: how to use a voltmeter/ohmmeter, full wiring diagram
