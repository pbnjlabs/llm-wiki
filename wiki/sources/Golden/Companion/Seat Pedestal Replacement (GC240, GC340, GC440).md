# Companion Replacement Pedestal Instructions (GC240, GC340, GC440)

1-page instructions for swapping the seat pedestal: remove seat, remove
seat-post bolt/nut/washers (retain one arc washer and the nut), unbolt the
old pedestal (4 bolts), install the new one with handle facing rearward,
reattach seat post with the new supplied M10 socket head cap bolt.
