# LiteRider Service Guide (GL110/GL140)

80-page service guide (LiteRider_SG_REVA_040711) — troubleshooting,
replacement instructions, and illustrated parts breakdown for the older
LiteRider generation. Uses a **Dynamics R-Series Controller** — the same
controller family named on GL111/141's and the Companion's electrical
diagrams, and its 9-code beep scheme matches
[[Flash-Beep-Diagnostics]] essentially verbatim (same code numbers/order/
meanings) — confirmed cross-model rather than assumed.

Contents:
- Component reference (circuit breaker, batteries, harnesses, Dynamics
  R-Series controller, motor/brake, control panel, throttle/speed pots,
  charger) with location/function/failure-signs/test/expected-reading/
  serviceable notes for each
- Scenario 1 (no power) and Scenario 2 (won't charge) voltage-check
  walkthroughs
- Beep codes 1-9 — see [[Flash-Beep-Diagnostics]] for the shared table
- Replacement instructions: drive wheel, drivetrain, throttle pot,
  battery, circuit breaker, battery harness fuse, controller, main
  harness, control panel, brake
- Appendix A/B: how to use a voltmeter/ohmmeter
- Appendix C: wiring diagrams (control panel, main harness, power/battery/
  intermediate harnesses, charger harness, circuit breaker)
- Appendix D: troubleshooting flow charts (visual restatement of the
  scenario/beep-code procedures)
- Illustrated parts breakdown for GL110 (pp. 41-55) and GL140 (pp. 56-76)
  — not itemized here, reference the PDF for part numbers

Notable: the "quarter test" (sliding a coin into a harness connector's
spring contacts to check they hold it firmly) is used repeatedly as a
low-tech continuity/tension check across multiple beep-code procedures.
