# Buzzaround Extreme Illustrated Parts Breakdown (GB118, GB148)

10-page IPB; electrical page read visually. The first EX parts list on
file.

- **Controller: Dynamics DR90-A01, 90 A** (3051600170, the Companion
  and LiteRider part); program **ZZ-PROGRAM-BZ8HD ("HD transaxle")**.
- Paddle (throttle) assembly, speed pot, key switch, horn, volt meter,
  **fuse box assembly** MBE-BZ-FBOX, motor intermediate connectors,
  main harness MBE-BZ8-MWH; accent light (GB148E).
- **U1** batteries in packs; **battery dock** MBA-BAT-DOCK; 3.5 A
  charger; Dynamic programmer MBC-DXHHP.
- GB148 pneumatic option: front/rear air tire assemblies MBW-BZ48-FATA /
  RATA.
