# LIT-MB-0008 / MBA-0014 — GB120 Kickstand Installation Guide

Adds a kickstand by relocating the front basket's mounting bracket: remove
the seat pedestal's rear lower bolt (6mm Allen) and the basket's mounts
(3mm Allen), install new kickstand-compatible mounts, reattach basket.

Note: kickstand presence changes the correct disassembly method in
[[GB120 Tiller Replacement Instructions]] (extend kickstand to stand the
unit upright, vs. flipping it upside down without one). Feeds:
[[GB120-Buzzaround-CarryOn]].
