# LiteRider Envy Illustrated Parts Breakdown (GP162)

7-page IPB for the GP162 LiteRider Envy power wheelchair. Confirms two
chassis variants sold under one model number: **GP162B** (basic frame,
seat post part shared with the older "LiteRider PTC GP160") and **GP162C**
(distinct frame component, seat swivel with a built-in lock mechanism).
Frame/shroud/decorative-plate parts are ordered per color (8+ color codes
each for main frame, rear shroud, battery box shroud).

Electrical system page lists parts for **two distinct controller
families** sold on this one model: "Dynamic" LiNX components (controller
DLX-REM060-A, joystick, power module, wire harnesses) and, separately,
"nVR2" components (joystick nVR2-40A, power module nVR2-40A) — confirms
GP162 is sold with either a LiNX or a VR2-family controller, not that one
superseded the other in the parts catalog.
