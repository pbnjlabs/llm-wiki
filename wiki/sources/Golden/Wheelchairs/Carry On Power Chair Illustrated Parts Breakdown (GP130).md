# Carry On Power Chair Illustrated Parts Breakdown (GP130)

5-page IPB (LIT-GP130-IPB, Rev. E). **The controller is a PG VR2**
(MBE-0061, "Controller, Vr2"), which the owner's manual doesn't say.

| Part | Number |
|---|---|
| Controller, VR2 | MBE-0061 |
| Joystick | MBE-0062 (mounting bracket MBH-0062) |
| Battery, Li-ion 24 V 12.5 Ah | MBE-0064 |
| Charger, Li-ion 24 V 2 A | **MBE-0028** (the GB120 scooter's charger) |
| Fuse | MBE-FUSE35A-BLADE, 35 A blade |
| Seat post connector with harness | MBE-0063 |
| Drive motors R / L | MBX-0007 / MBX-0008 |
| Battery travel bag | MBA-0225 |
