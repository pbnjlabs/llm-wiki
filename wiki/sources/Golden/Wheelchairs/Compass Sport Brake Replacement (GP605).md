# Compass Sport Brake Replacement (GP605)

3-page, ~30-minute, 28-step procedure to replace either side's drive-motor
brake on a GP605. Strip covers/shrouds/seat post → cut factory tie-wraps
(3 left, 2 right — new ones applied on reassembly) → unplug M1 (right) /
M2 (left) motor harnesses → support the chair so wheels clear the ground →
pull snap rings → slide the drive assembly out on pivot shafts → unplug
the 2-pin brake harness → swap the labeled left/right brake (4 screws,
lever in neutral) → reverse, with side-specific harness routing/tie-wrap
counts (step 19 for right-side-only rewrap) → **plug the left motor
harness into M2, right into M1, and the power harness into the "SHARK"
module**. So this (2011) GP605 used a Dynamic Controls **SHARK**
controller ([[Shark-Diagnostics]]). The 2017
[[Compass Sport Service Guide (GP605, LiNX)]] shows a LiNX controller, so
later GP605s changed.
Ends with a mandatory test drive.
