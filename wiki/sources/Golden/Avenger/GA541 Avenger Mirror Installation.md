# GA541 Avenger Mirror Installation Instructions

1-page supplement: cut the end of the tiller hand grip (only the end —
over-cutting damages the tiller), swap the knurled plug on the mirror
mount for the one included in the package, install the mirror into the
now-exposed metal tube, adjust while seated, tighten.
