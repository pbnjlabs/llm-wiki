# LiteRider Brake Replacement (GL110/GL140)

2-page procedure (P/N MBD-LRB, ~15 min). Purpose: replace the old-style
brake with a rearward-facing freewheel lever (new style faces upward, more
convenient). Steps: seat/battery/basket off → separate front/rear halves →
remove right drive wheel (retain axle key) → mark and remove 4 brake
screws off the motor → disconnect 2-pin brake connector, remove old brake →
install new brake (verify puck moves freely when disengaged), reconnect →
re-tie-wrap harness away from handle → swap red rubber handle for yellow
(visibility) → reinstall wheel/halves → check ~1/4" lever clearance from
frame, bend lever if needed → reassemble, test.
