# Proflex Seat Instructions

3-page assembly/adjustment manual for the metal-frame Proflex seating
base — this is the physical product behind the "SMP" code in the
[[Golden-Seating-Systems]] fitment matrix. Covers back
lock/recline-release, push handle height, back angle, seat "dump" angle,
and swing-away leg rest length/angle, each independently adjustable.
