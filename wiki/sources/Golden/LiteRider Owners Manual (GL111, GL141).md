# LiteRider Owner's Manual (GL111/GL141)

42-page operator manual for the current LiteRider generation. Specs table:
300 lb capacity, 5 mph, rear-wheel drive, 90 Amp controller (both models),
2×22AH batteries, off-board charger, freewheel mode, electro-mechanical
brakes. GL111 is the 3-wheel model, GL141 the 4-wheel.

Contents: intro/packing list, safety (mounting, inclines — 6° max, backing
down a slope procedures, EMI/RFI), specs, operation (control panel, speed
dial, key switch, Delta Tiller throttle lever, seating adjustments,
freewheel mode), riding (mounting, basic driving, steering, tight spots),
disassembly/assembly (drivetrain release lever + yellow tab alignment,
deactivate block under a new battery pack — must be removed before first
power-on), transporting, care/maintenance (battery charging: 6-8hr daily,
12hr initial conditioning), diagnostics, warranty.

**Diagnostics**: a 1-9 beep code scheme — matches
[[Flash-Beep-Diagnostics]] essentially point-for-point (battery low/very
low, [3=high voltage, undetailed in this OM], current-limit overload,
brake fault, throttle-neutral fault, throttle/pot fault, motor voltage
fault, other internal fault). Printed on the back of the battery box for
field reference (same convention noted in the older GL110/140 service
guide).

**Warranty**: identical structure/tiers to [[Golden-Scooter-Warranty]]
(rev. 11.17, same revision already on file from the GA541 Avenger OM) —
lifetime frame, 2yr drivetrain/electronics, 1yr batteries/wear parts.
Explicitly lists "LiteRider Series: GL109, GL111, GL141" as covered — note
**GL109**, not GL110, in this covered-models list; another instance of the
warranty text's named part numbers not exactly matching the raw manual
collection's model numbers.
