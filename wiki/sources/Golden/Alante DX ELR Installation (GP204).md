# Alante DX ELR Installation (GP204)

1-page elevating-leg-rest (ELR) install for the standard-seat Alante DX
(GP204): mount a receiver tube under the seat, insert left/right hangers,
bolt the tube to the seat, reinstall the seat, then hang the ELRs on the
frame and swing them inward to lock.

For optional (non-standard) seat sizes on the Alante DX, the document
explicitly redirects to different part numbers shared with the **Alante
GP201** and **Compass Sport GP605** — same legrest hardware family across
those three models. See [[Compass Sport ELR Installation (GP605)]] for
the parallel procedure on GP605.
