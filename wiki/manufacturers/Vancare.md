# Vancare

Manufacturer of **ceiling-lift track systems and accessories** (track,
trolleys, turntables, transition gates, charging hardware). Discovered
via a single 213-page installation guide filed under `MANUALS/Prism/`
(`Ceiling Lift Installation Manual NEW.pdf`) — **not a Prism-authored
document**, but genuinely relevant to Prism's ceiling-lift line: the
guide's own compatibility tables confirm Prism's [[C-450-C-625]] (C-450/
C-625/C-800/C-1000) and [[P440]] (P-440/P-600) lifts are designed to run
on Vancare track hardware, alongside part numbers for **three competing
track brands** — Mikyway, Guldman, and ArjoTrack — that Prism's portable
lifts also support via different trolley adapters.

This is a different situation from the AutoSlide/Open Sesame or
Harmar/Bruno misfiles elsewhere in this wiki: those were raw files that
ended up in the wrong company's folder by accident. This one is filed
under Prism because it's the **track-system supplier documentation** a
Prism ceiling-lift dealer would actually need — a legitimate cross-brand
OEM relationship (like most ceiling-lift companies, Prism doesn't
necessarily manufacture its own track). Kept as its own manufacturer
page rather than folded into Prism's, since the document's actual
author/warranty/support chain is Vancare, not Prism.

## Product line

- **[[Ceiling Lift Installation Guide]]** — comprehensive track-system
  install manual: planning/site-survey workflow, Basic (single-path)
  track, Full Room Covering (X/Y traverse) systems, Transition Gate
  System (TGS), turntables, structural attachment methods split by
  setting (home-care wood framing: top-down/bottom-up/wood-blocking/wall
  mount; institutional: concrete slab, structural beam/open web joist),
  power supply and charging (End Point docking-station vs. Omni/Constant
  continuous-charge TransStrip systems), ceiling lift mounting, and a
  full testing/inspection/preventative-maintenance program (150% load
  test, 100% function/deflection tests, span and cantilever charts by
  lift capacity).

## Cross-manufacturer confirmation

The Hand Control / Parts section (p.174) explicitly tables Vancare part
numbers against **C-450, C-625, C-800, C-1000** (Prism's "C-Series") and
**P-440, P-600** ("Portable Ceiling Lifts") — this is how [[C-450-C-625]]
and [[P440]] were confirmed to have two undocumented sibling models
(C-800, C-1000, P-600) with no manual of their own on file yet. The
charger power-requirements appendix (p.204) separately confirms the same
charger serves all four C-Series models.
