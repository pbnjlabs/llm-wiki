### 4. On site: install

- [ ] 1. Tower stood on the pad

- [ ] 3. Upper gate (top landing gate) installed

- [ ] 6. Clearances checked: running clearance ___ in, upper sill ___ in (both 3/8–3/4 in)
- [ ] 7. Lift anchored (Bruno: four 1/2 × 2-1/2 in min. anchors)
- [ ] 8. Upper limit set; drive nut retention hardware **not touched**
- [ ] 9. Call/send and upper gate wired, in conduit; call/send box 3–10 ft from the platform
- [ ] 10. Gate actuator installed and adjusted
- [ ] 11. Covers installed (Bruno top cover pushes the service switch back down; Harmar: out of Service/Bypass Mode)

### 5. Test, photos and handover
**Test all functions.** Minimum (VPL-3100B p.31; use the unit's manual):
- [ ] Underside panel stops down travel (several spots, every station)
- [ ] Top cover off → all controls dead
- [ ] Final limit → no movement
- [ ] Door/gate interlock: open → no movement; opens only at the top
- [ ] Platform key switch off → platform controls dead
- [ ] Call/send key off → station controls dead
- [ ] E-stop stops the unit
- [ ] User ran the lift with the tech present

Photos:
- [ ] Multiple pictures of the lift from the landing
- [ ] Wide-angle picture of the completed job
- [ ] Serial number plate
